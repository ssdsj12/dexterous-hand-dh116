# DH116 表格坐标对齐设计审计

Baseline / Candidate: b5666c2 + dirty worktree；本轮仅资料核对与设计，未改控制代码、USD 或驱动。

阶段：T500 下 DH116 非线性耦合前置。用户确认 PCHIP、状态相关导数与无接触验证路线。

输入：两份 20260112 XLSX、用户手册、左右 V2 URDF、既有 USD 验证器。core0 用标准库 XML/ZIP 读取表头、图表文字、SHA、关节 axis/origin/limit；用 pdftotext 核对手册。未运行 Isaac。

发现：两表图表没有定义指尖角参考坐标系。拇指表到45°、手册屈伸到30°；四指表到60°、手册到80°。四指源从动下限0.011072rad，与表格零位存在待解释差异。左右拇指关节零位不同，不可统一按镜像翻转符号。

结果：完成书面接口、有效区间、来源身份、插值/导数一致性与验收条件设计；坐标对齐仍未验证。不得以有限差分自洽代替厂家姿态证据，不启动物理开合或抓取。

下一步：书面审阅后拆分实施计划，先实现可审计数据层与候选映射验证。厂家坐标定义不足时保留拒绝动作状态；无效输入不污染最近安全状态。
