# DH116 独立空载食指往返验证

Baseline/Candidate：b5666c2 + dirty worktree。用户授权明确的仅仿真驱动配置，Inline Execution。阶段为DH116单手独立驱动/耦合检查，不是双Panda或wire。

新增no_load.py、verify_dh116_no_load.py及测试。合成参数：主动PD刚度1 N·m/rad、阻尼.05 N·m·s/rad、力矩上限.1 N·m、速度上限.3 rad/s；从动驱动为0，由线性mimic约束。固定掌根、无重力、自碰撞开启。source为SHA固定linear_limits_verified_v3，源文件不写入。初始化一次关节状态，之后只发目标并推进PhysX。

目标：6主动起始.2rad，食指在2–6秒以余弦往返.2→.3→.2rad，总计8秒、dt=1/240。门限：跟踪<=1度、耦合<=.5度、速度<=.31rad/s，非有限或主动越限立即停止试验循环。没有以修改阈值获得通过。

## 执行与结果

- 单测先RED 2 failed（缺模块），实现后GREEN；DH116全部当前测试49 passed in 0.75s。
- 左trial1初始化失败：NumPy float64初始配置与Isaac float32缓冲冲突，physics_stepped=false。初始配置显式转换Python float后重跑；该失败证据保留。
- 左trial2、右trial1各1920物理步完成，summary passed=true。两侧最大跟踪0.00376379548 rad（约.21565度）、最大耦合5.17884505e-6 rad（约.000297度）。检查实际JSONL中食指运动范围，而非只凭目标/进程退出码。
- 证据目录：主仓库assets/dh116_v2/no_load_left_trial2及no_load_right_trial1，各含summary.json/trajectory.jsonl。trial1失败在no_load_left_trial1。
- Kit关闭阶段滞留超过一分钟；确认summary/1920行轨迹已落盘后，对本次已核验PID 24885、25043发送SIGTERM释放资源，未删除证据。不能将这种结束方式当作正常退出验收，关闭生命周期仍需修复。
- 实际食指角范围两侧均0.200000003–0.299850672rad，结束0.200001284rad，最大速度左右0.077422149/0.077422209rad/s，确有动作而非仅目标变化。

GPU0、core0、OMP/MKL/OPENBLAS=1，命令从Go2Pvcnn运行：

```bash
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
PYTHONPATH="$PWD" taskset -c 0 /home/xk/miniconda3/envs/go2/bin/python \
scripts/verify_dh116_no_load.py --side left --headless --device cuda:0 \
--output /home/xk/coding/M1/assets/dh116_v2/no_load_left_trial2
```

输出目录必须不存在，复跑用新目录名；right同理。不应覆盖既有证据。

## 边界与下一步

通过的是无重力单食指小幅往返及全手状态的耦合/跟踪门，不是六主动逐指验证、全幅开合、重力负载、手掌位姿、实测Jacobian或抓握。自碰撞开启但没有独立接触传感器/全表面间隙验收，contact_clearance_validated=false。下一步补全其他手指及拇指的分阶段空载扫描与接触监测，再考虑双Panda安装。不得把合成增益当厂家参数，不训练、不操作wire。
