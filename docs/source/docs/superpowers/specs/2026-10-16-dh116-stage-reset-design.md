# DH116 上方对捏阶段初始化

## 决策

用户2026-10-16同意采用阶段状态库：优先练习尚未通过的阶段，不每次重跑落定和接近。参考本地2610.12465v1论文A.2的中间状态初始化，不宣称实现其完整SGS/PPO采样算法。仅上方对捏，桌面滑入取消。Inline执行，CPU单核、一个物理实例；当前trial2不热改或重启。

候选方案：只加载关节角不能恢复柔性杆与接触；逐位恢复PhysX内部缓存缺少可靠接口；采用有来源的完整物理状态初始化并重新验证接触，作为本方案。它不是位级确定性断点续跑。

## 状态库及来源

允许入口approach/close/hold/lift。分别要求来源通过落定/接近/闭指/保持门。保存源run、step、时间、阶段通过证据、文件SHA与状态摘要，不凭命令目标或运行中passed布尔值晋级。失败帧不能自动成为合格入口；保留最近合格阶段入口供下一次尝试。若没有所需入口，只退回最近可验证入口，明确报告缺失，不静默从最初重跑。

每侧保存按名称映射的完整物理关节q/qd、根位姿/速度、臂手控制目标。杆保存位置、速度、director、omega，以及静止长度、静止应变/曲率、材料和离散配置；不得把变形后几何重新定义为无应力杆。保存固定材料抓取ID、原落定高度、夹持锚点、力目标、驱动/耦合步长/安全阈值和资产/后端版本身份。源文件保留不变，新工件独占写入、校验完成后原子发布。目录存在不代表状态有效。

现有JSONL仅作为候选来源，缺少静止结构或配置身份时必须从可核验源补齐，否则拒绝，不声称日志具备完整恢复能力。

## 恢复顺序

1. 在创建物理任务前校验schema、SHA、型号/左右手、关节名称、尺寸、有限值、旋转正交性、限位、材料/静止结构与配置兼容性。
2. 重建相同静止杆和机器人模型，注入物理状态与控制目标，刷新机器人运动学；重算杆几何/应变和接触。重建接触预测缓存，不重放上一轮已经施加的冲量，不带入陈旧外力。
3. 进入独立restore_validate状态，冻结任务推进，保持原重力与接触反力控制。所有碰撞、速度、力矩、压入量门持续启用。恢复后的测量时间从零连续递增，不用伪造前序时间跳过状态机。
4. approach入口需重新检查落定及全臂几何；close入口需重新检查位置≤2mm、法向≤5°和全臂几何，至少连续0.1s有效。hold/lift入口需重新建立四点有效接触及预载，连续保持1s，固定材料滑移≤2mm，然后才允许下一动作。不能继承累计接触时长直接获准抬升。
5. 恢复不稳定或任何保护失败即保存并中止；不得自动关闭重力、放宽保护、绑定wire或默默换姿态。

## 验收与结果语义

阶段结果和端到端结果分开：记录初始化来源、复验时长、每个实际执行阶段的PASS/FAIL/NOT_RUN。来源阶段标为imported_evidence，不冒充本轮执行；局部恢复试验不得设置continuous_grasp_passed。仍需最终从初始状态执行一次连续抓取和规定重复验收。

测试覆盖：损坏/缺失/pin不符/越界/NaN/非正交/前序证据缺失拒绝；杆静止结构不被覆盖；接触时长清零和重复冲量防护；阶段局部时钟；复验失败不能晋级。实际分开验证落定状态恢复、接近终点恢复、夹持状态恢复，并对照重力、杆形、速度、载荷和滑移的恢复瞬态。全部保留物理轨迹，不使用绑定伪成功。
