手册主动范围为侧摆 0–60°、拇指屈伸 0–30°、四指屈伸 0–80°，与表格和 URDF 不完全一致。模型有效区间必须取经过坐标转换后的表格、已适用手册范围和源关节限位的交集，不能直接使用表格最大角作为动作最大角。手册型号与 V2 资产版本关联也应记录；不能静默扩大范围。

左右源 URDF 的 thumb flex 与 follower 均为局部负 X 轴，但其关节零位变换不同。其余四指大致为局部正 X 轴，带小的非 X 分量；左右镜像不意味着所有关节角都应取反。源四指从动下限是 0.011072 rad（约 0.634°），而表格位移从零开始。该差异可能涉及零位定义，不能自行加偏置后宣称标定完成。

USD 基准使用 assets/dh116_v2/portable 下的独立资产；旧 linear_approx_verified_v2 只作比较，不作为新的非线性运行资产。portable SHA 沿用现有验证器记录并在读取时核对。

## 坐标标定合同

每侧、每个耦合对都显式记录：主动与从动关节名、body0/body1、axis、localRot0/localRot1、零位、角度单位、表格输入坐标、输出角相对的参考体，以及符号与偏置的依据。USD 的旋转轴名本身不足以确定世界或掌坐标方向，必须与局部变换组合。

首先区分表格输出是相邻指节的相对角，还是指尖连杆相对某个固定参考体的绝对角。相对角可以用符号与零位转换；若是绝对角，必须先结合上游姿态还原相对转动，再求导，不能简单套 `q_follower=-table(q_active)`。必要时使用相对旋转矩阵并沿关节轴求有符号角。

XLSX 内图表仅给出角位置/位移名称，没有参考坐标系说明；当前证据不能唯一确定转换。实施时允许先编写候选对齐诊断与插值核心，但 `alignment_verified=false` 必须禁止接入物理动作。若源模型和手册仍不能消除歧义，需厂家角度示意或与同一驱动角对应的可靠参考姿态；不得仅凭“看着像闭指”批准映射。

对齐报告至少比较零位、范围内中间位和末位的左右链姿态，记录候选映射及排除理由。运动学有限差分只能证明实现自洽，不能证明厂家角度解释正确。

## 插值与接口

推荐 PCHIP 保形分段三次，而非分段线性或全局高阶多项式。分段线性的节点导数不连续；全局多项式可能在端点过冲。PCHIP 保持单调数据形态并提供连续一阶导数，但不承诺二阶导数连续。

原表按严格递增输入检查，不静默排序、合并或丢弃重复样本；拒绝非有限值、空表、逆序与坏列。导出带输入 SHA、列名、单位和转换身份的只读标定数据，不让控制循环解析 Excel。统一运行单位为 rad；边界仅容许明确的数值舍入容差，不允许范围外外推或静默钳位。

新模块与 linear_coupling.py 分离。接口提供展开完整 11 关节角、计算 11×6 导数矩阵、按实际关节名折叠 Jacobian，并返回当前有效性。拒绝输入时不得改变最近安全状态。线性接口保留供已有回归使用，不能把旧测试通过视为新模型通过。

对于主动角 q、完整角 F(q)，定义 C(q)=∂F/∂q。主动行是单位映射，从动行使用坐标变换后的插值导数，包含符号、偏置对应的输入变换及绝对角转相对角所需项。速度采用 qdot_full=C(q) qdot_active；同一点、同一参考系的 Jacobian 采用 J_active=J_full C(q)。

需要先将 COM Jacobian 平移到实际目标点，再折叠列；点位必须区分 distal 原点、掌心与标定指腹。角度和导数使用同一组多项式系数，不能分别拟合两条不一致的曲线。

## USD 和动作接线

新派生资产单独保存，保留 source SHA、coupling SHA 与派生 SHA。非线性运行路径去除旧固定比例 mimic；不得同时启用旧 mimic 和非线性从动目标。

第一阶段只做离线 FK 和可视化姿态扫描，不将直接设关节状态称为物理开合。第二阶段采用显式配置的仿真跟随器消费展开后的角度和速度目标，监测实际 11 关节状态是否满足耦合。此跟随器属于仿真近似，不等同真实机械闭链，也不能据此推断抓持力或实物扭矩。

现有派生资产驱动为零；本设计不凭空提供驱动增益、力矩或速度。物理开合必须另有明确的 DH116 仿真配置与授权，标明不是厂家实测参数。缺失配置时退出并报告，不用 importer 默认大限值或 O6 参数补齐。

## 验证顺序与通过条件

1. 数据层：SHA/列身份、样本数、严格递增、非有限/越界拒绝，保留原表节点值；角度节点误差目标 ≤1e-10 rad。
2. 插值层：节点、中点、端点及双侧导数检查；内部点中心差分与解析导数误差目标 ≤1e-5 rad/rad，端点用单侧方法并报告步长收敛。
3. 对齐层：左右轴与零位、相对/绝对定义的证据齐备；无法确认时保持未标定，不进入物理动作。
4. 运动学层：对真实 USD 读取的五条手指链执行命名列重排和错误输入测试；位置 Jacobian 最大差分误差目标 ≤1e-6 m/rad，并用多步长验证数值稳定性。姿态 Jacobian 使用旋转增量而非欧拉角差分，目标 ≤1e-5 rad/rad。离线验证不替代 PhysX 测量。
5. 空载物理层：在显式仿真配置下先小幅慢速单指，再全手及双手；目标在标定有效区间内，初步耦合跟踪门限 0.5°，任一非有限状态、越限或非目标接触立即安全停止。若门限不满足则报告失败，不靠放宽门限获取成功。
6. 双 Panda 与 wire：空载门通过后才做安装坐标、实际点 Jacobian、指腹标定与全臂保护，再进入接近/闭指/夹持/抬升；不包含在本轮完成声明中。

CPU 计算限定单核和单线程。GPU0 仿真先单环境，测试结果与实际配置一起记录，不能只凭进程退出码判成功。
