# DH116 独立工作目录设计

## 目标与边界

将当前 DH116 固定双 Panda、桌面柔性 wire 工作流独立整理到 `/home/xk/coding/dexterous hand`。用户已确认采用独立复制、验证后切换；原文件暂留备份，不删除或搬移原项目。当前实际试验不得被迁移中断。

本次不改变关节耦合、驱动参数、接触模型、碰撞阈值、阶段资格或抓取算法。隔离成功不等于抓取成功。

## 目录

- `src/`：DH116 控制、运动学、Jacobian、碰撞、接触、阶段保存/恢复及其必要共享模块。
- `scripts/`：DH116 资产准备、校准、验证与演示入口。
- `tests/`：相关回归和独立性检查。
- `assets/`：DH116 USD/网格、双 Panda 必需 USD/网格、桌面和 wire 配置、接触网格、参考点。
- `vendor/DeformX/`：本地已修改的实际柔性杆后端，保留许可证、版本及修改来源；不复制虚拟环境或无关仓库历史。
- `resources/manufacturer/`：普通 DH116 V2.0 的厂家 URDF/MJCF、手册与角度表，保留原始文件及 SHA。
- `configs/`：当前可使用的参数与新目录配置。
- `archive/`：历史试验、快照、状态和证书，保留原字节及来源，不将历史路径替换后冒充原证据。
- `runs/`：新目录下未来产生的运行记录。
- `docs/`、`README.md`、`CODEX_RESUME.txt`：相关设计、进展、操作命令、迁移限制和恢复入口。
- `migration_manifest.json`：来源路径、目标路径、SHA、分类以及迁移/校验状态。

第一阶段可保留必要的 `go2_pvcnn` Python 命名空间以缩小变更；目录中不包含无关任务注册、机器狗训练、O6 资产、OakInk 转换或其他物品。名字包含 O6 但被 DH116 使用的公共接触桥只抽取必要依赖，不能按文件名误删。

## 依赖与路径

递归检查 Python 静态/动态导入、USD reference/payload/sublayer/纹理、脚本默认路径和运行时资源。共享 Panda 网格及 DeformX 后端是当前 DH116 工作流的必要部分。

运行资源使用相对资源引用或从项目根解析路径；支持目录名中的空格。新目录不得通过符号链接、旧工作树 PYTHONPATH 或旧资产绝对路径保持隐式依赖。Isaac Sim/Isaac Lab、CUDA、现有 go2 Python 环境属于显式外部软件依赖，不复制进项目；记录版本和启动方式。

原始 USD 和历史证据作为归档保留。需要修改引用的 USD 写入新运行资产，重新生成 manifest 和 SHA。不得修改历史状态文件的 pin 来使它通过新配置检查；只有真正兼容的状态才可恢复，否则标明仅归档并生成新合格状态。

## 活动试验处理

迁移时旧 PID6780 的输出仍在变化。活动运行先登记为 `live_pending`，不宣称它的复制品完整；原进程终止后再同步、逐文件核验。迁移不自动停止进程、不新增并行 Isaac 实例。数值任务保持 core0/单线程。

## 验收

1. 所有纳入的代码、资源和厂家资料有来源清单；未修改文件 SHA 与来源一致，改写文件同时记录旧/新 SHA 和原因。
2. 新目录运行入口不依赖旧 M1/DeformX/桌面资源路径；历史归档中的旧路径允许存在且明确不可直接运行。
3. 清理旧 PYTHONPATH 后，新目录相关模块导入及回归通过；测试报告记录排除项，不能用少量测试冒充完整覆盖。
4. 在新目录解析全部运行 USD 依赖、重验关节/限位、接触网格与配置证书；运行期不得回落旧目录。
5. 当前旧 Isaac 试验结束后，串行执行新目录的最小实际 Isaac 验证；保留重力、接触反力和碰撞保护。
6. README 给出带空格路径可直接执行的检查/测试/运行命令，说明最新抓取阶段和未完成项。
7. 新项目验证完成前不删除原件；清理重复文件需要另行确认。

## 执行顺序

依赖清单与迁移测试 → 复制静态代码/资源/资料 → 路径及资源引用适配 → 新 SHA/配置生成 → 离线独立性回归 → 活动证据最终同步 → 单实例 Isaac 验证 → 更新入口与交接。任何缺失资产或校验失败均明确报告，不以软链接或伪造状态资格绕过。

## 设计自审

保留原件和运行连续性；明确静态副本与活动输出区别；区分新运行资产与历史证据；不复制环境、不混入无关项目；不承诺历史状态可跨 SHA 自动恢复；尚未实施复制或代码改写。
