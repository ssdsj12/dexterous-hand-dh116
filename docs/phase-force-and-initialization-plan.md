# 分阶段向上作用力奖励和轴下初始抓姿

用户明确要求新增抓取/lift作用力奖励，并将初始抓取位置放到中轴以下。
现有每手2–12N法向目标、close目标锁定、PI、接触权重.5/2、实际30mm/.5秒成功不变。

实施：
1. 新stateless phase-force reward模块，抓取phase1/2每秒最多2分，基于各手正常向上
   法向力相对半物重归一化；lift phase3每秒最多5分，基于各手法向+摩擦向上力。
   负向合力、无接触、超12N、失败和无效测量不发正奖励。真实传感器值不夹平。
2. Env将真实每手normal+friction送Task，两个奖励分项与现有奖励一起进入PPO。
   无新增观测状态；CLI/合同/TensorBoard明确版本，旧奖励不能静默续训。
3. 从source USD FK及碰撞网格推导新初始化，四个thumb/index指腹低于轴至少约.5mm，
   目标约1mm，同时table clearance>=.3mm，无初始穿透，杆仍自然落在原桌面。
   不改硬限位、力矩、摩擦、物体质量或成功判定。
4. 纯tensor及集成红绿回归；静态几何审计；随后小规模真实Isaac复位/教师控制验证。
   没有有效接触时不能用指腹位置替代实测接触位置，不宣称已产生支撑或成功提升。
5. 更新默认训练/检查/手动启动配置；保持大规模PPO停止，先验证新抓姿。
