# DH116 Free Grasp Implementation Plan

> **For agentic workers:** Use subagent-driven-development for bounded tasks, with root integration and review.

**Goal:** Recognize arbitrary hand-object contacts and permit reachable close actions, correct the reproduced coupling failure, then start fresh PPO.

**Architecture:** Keep legacy four-pad channels for diagnostics. Add explicit object-link loads, grouped finger/palm observations and per-hand loads; scalar and batched control consume the same semantics. Version contacts, observations and action mapping together; reject old contracts.

**Tech Stack:** Python, NumPy, PyTorch, IsaacLab/PhysX, SB3 PPO.

## Global Constraints

- Single Isaac instance, CPU0 and numeric threads=1; preserve original rigid object pose, material, mass and drive effort limits.
- 20 actions; no prescribed four-point grasp. Actual object lift >=30 mm for 0.5 s remains success.
- Contact potential 0..10 N ->0..5, used as a difference, excludes table contacts.
- New run uses fresh policy/optimizer/counters, target 2048 environments and 1024 episodes per environment; reduce only if measured capacity requires.
- Do not relax mimic hard threshold or claim a root cause without reproduction evidence.
- Root owns simulator execution and final tests/launch. Agents may inspect and edit assigned files, but must coordinate tests to keep single-thread workload.
