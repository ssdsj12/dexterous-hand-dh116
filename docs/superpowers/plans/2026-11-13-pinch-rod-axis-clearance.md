# Pinch 固定关节闭合路径的杆轴静态姿态构造

基线：5d159d93a1119d3c11b9fa13b30ca7f57622c02e。不是重跑耗尽的局部 SQP、Yaw 或 World-Tilt 搜索。

## 假设与边界

现有左手接触候选达到双指 SDF 目标，但 source finger13 的整条闭合路径未达到运行时 2.1mm 桌面净空。绕**杆轴**而不是 base 原点改变固定 Reset 姿态，可改变相对桌面高度，而保留理想直杆上的接触相对位置。此性质不能替代对离散实际杆节点的重新验证，也不能修复右手已有的非目标碰撞或未接触。

独立 CPU 构造范围：静态杆轴角度 ±15°；左右各一条原关节路径，不优化 q、不改变原最大0.3rad/s、160/480秒闭合时长和24D合同。每侧161个原路径状态，最多161个旋转后状态；共644状态，90秒墙钟。无 Isaac、无 GPU、无 PPO、无新原生配方。不是扩用旧原生预算。

## 实施与测试

1. 先写 sinusoid 可行域、周期多区间、坐标组合、连续运动余量、关节合同和独立门槛的失败测试。
2. 对全部 source17 与 locked-cooked5 顶点，把桌面条件写为 a cos θ + b sin θ ≥ c。解析求所有可行区间，不做角度网格试探。
3. 每条原关节路径的 travel bound 除以320，覆盖161个采样点之间的连续运动；另增加1nm数值安全余量，不减小2.1mm门槛。
4. 冻结选角规则：从可行区间选择最接近原姿态的内点；不以原生成功为由事后挑选数据。
5. 重新计算原 FK 并核对旋转矩阵组合；对实际冻结41杆节点重新取 SDF，对非目标几何和完整305..308mm初始沉降包络分别检查。
6. 报告最小净空、指腹离散节点SDF、法向、初态与全路径阻断；任何 CPU 结果都不自动授予原生或Teacher资格。

后继：左手仍需完整必需指腹路径深度、实际Reset、安装/碰撞/接触/自然退出验证，特别注意极小桌面余量；右手需要独立接触构造。保持Tripod/Power独立，不复制Pinch失败姿态。
