# R0 measured approach source
Goal: bind the existing same-clock actual pad/rod geometry to R0 approach progress, without claiming contact or inventing a reset measurement.
Architecture: an opt-in CPU/readback adapter reuses MeasuredClosureGeometry.validate to independently recompute every saved SDF result. It uses the actual parameter getter radius and actual solver nodes, keeps each pad gap and identity, averages positive sampled-node gaps within each hand, and supplies only approach_distance_m. Missing SDF coverage stays NA. This is discrete-node geometry, not exact continuous closest distance or contact.
Keep Pinch-only qualification explicit; Tripod/Power require their own actual geometry/recipes. Old files and defaults remain unchanged. A read-only optional replay mode compares the same pinned 16-step ledger, no Isaac and no new steps. The saved reset lacks this exact metric and remains unknown; the first approach delta cannot be recovered by borrowing the first post-step sample.
Steps: red tests for source/clock/coverage; implement source and opt-in replay; CPU/new+old regression; record the real per-control change and unresolved stability/hold; protect, report, Registry/readiness, Ubuntu commit and Windows publication.
