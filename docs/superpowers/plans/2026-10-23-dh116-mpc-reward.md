# DH116 MPC-Aligned Reward Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add dense reward shaping for hand-only DH116 MPC collection without changing replay phases or physical safety qualification.

**Architecture:** A pure reward function consumes measured/proposed actions and existing contact/lift measurements, returning a scalar and named terms. The Isaac collector applies it per action and stores aggregate diagnostics. The existing MPC reference and qualification helpers remain authoritative for their respective roles.

**Tech Stack:** Python, NumPy, pytest, existing Isaac Lab collector.

## Global Constraints

- Preserve all pre-existing dirty and untracked worktree changes.
- Keep hand-only action dimension at 12 and retain `mpc_action` as the MPC reference.
- Do not add unobserved approach, slip, or deformation rewards.
- Keep reward separate from abort and physical qualification gates.
- Do not launch Isaac for unit-level reward changes.
