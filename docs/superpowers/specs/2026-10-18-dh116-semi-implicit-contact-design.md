# DH116 保持物理参数的半隐式接触积分

状态：用户已确认方向及本详细设计；按 Inline Execution 实施，尚未切换运行。

## 目标与范围

降低刚性切向阻尼造成的细步长成本，保留柔性杆、原摩擦参数、四指腹接触以及机器人反作用力。不能承诺达到实时；通过数值验收后再测整机速度。只改接触积分，不重写机器人控制、抓取姿态或材料模型，不引入绑定线缆。

CPU 可使用用户最新授权的全部核心；同时只运行一个 Isaac 实例。

## 已有证据与方案选择

本地 runs/forward_gui_render10 中的静态及运动细步长探针显示，2.5→1.25 µs 对比满足既有误差要求。10 µs 旧显式积分未通过静态接触收敛检查，不能作为精度基准。该结论不代表实际机器人抓握已经成功。

三种路径：

- 细步长显式：作为独立参考保留，成本较高。
- 冻结单个子步几何、联合求解速度相关接触的半隐式方法：本次推荐，范围限于接触子系统。
- 对杆位置、转动及接触全部做非线性隐式求解：改动和验证范围更大，本阶段不采用。

## 接触求解契约

每个杆子步先更新半步位置和姿态，再在该几何下查询原精确网格距离、法向及接触点。保持原 quadrature 权重、节点分配和转动力臂；无接触不生成粘附力。

以同一子步中的非接触力预测自由广义速度 u_free；接触求解满足：

    u_new = u_free + h M_eff^-1 B^T f
    v_rel = B u_new - v_mesh
    Fn = max(0, k * penetration - nu * dot(v_rel, n))
    Ft = -min(c * |v_t|, mu * Fn) * v_t / (|v_t| + 1e-14)

f 包含原积分权重。M_eff 必须从实际杆动态更新中的平移及旋转响应推导，包含当前伸长相关因子；不得仅用静态惯量近似而略去原动态算子的因子。杆内力、重力和原解析阻尼的处理顺序应明确保留，接触算子仅替代接触贡献。

四个指腹同时求解，不能各自按孤立杆质量计算。桌面若对该步产生速度相关接触，也必须纳入同一耦合问题，按桌面原有接触规律求解，不擅自套用指腹参数。动网格速度包含平移与角速度，不把规定边界解释为无限抓握力。

采用阻尼 Newton/线搜索解上述速度残差，有限差分 Jacobian 可用于首版离线参考；性能版再使用解析或分块结构，并对比等价性。每步最多 50 次迭代。要求最大广义速度修正残差通过分量尺度归一检查：平移绝对容差 1e-8 m/s、转动 1e-8 rad/s，均加 1e-6 相对项。此迭代容差不是轨迹精度证明。

不收敛、非有限、质量响应非法时返回明确失败，不静默降低摩擦、削弱刚度或继续用不合格结果。首版不自动降步长重试，以避免隐藏部分步进及重复冲量；后续如需自适应应另加完整回滚测试。

## 与现有步进及反作用力接线

为实验模式设置独立动态更新适配层：非接触速度预测 → 联合接触解 → 一次提交速度 → 保持原后半步几何更新。不得在原接触回调中先改速度，又让 PositionVerlet 重复施加同一力。

求解器返回每个接触的线性冲量及关于接触点力臂的角冲量，按原坐标定义转换到各指腹质心。机器人接收精确相反的已接受冲量，不能重新通过旧显式力回调估算。桌面反作用单独记账，不计入手指负载。采样器按成功接受子步累计载荷、持续时间和冲量，失败步不计入成功证据。

记录迭代数、残差、实际子步、各通道冲量、相对切向耗散、总线/角冲量平衡和耗时。运动边界可以对杆做正功；不能以杆总能量上升单独判错，应检查包含边界功的能量账和相对切向耗散。

## 验证与启用条件

1. 单点阻尼解析例、零接触、滑动/零切向速度、多个接触共享节点、旋转力臂、运动网格、桌面共同接触；检查权重、作用反作用和无重复施力。无接触路径应恢复原步进结果。
2. 使用相同初态及参数，复跑静态双侧和 10 mm/s 运动边界各 100 ms；以 1.25 µs 显式结果为参考。接触间断及实际捕获阶段还须增加桌面离开/重新触碰工况。
3. 候选子步从 2.5、5、10 µs 逐级测试，只有通过才试 20 µs 等更大步长。外层暂固定 100 µs。每个候选均需自身步长减半检查，不能只看单次对照。
4. 沿用既有误差门槛：最大中心线差 ≤0.2 mm；各通道峰值力差 ≤max(0.05 N, 参考峰值5%)；各通道累计线性冲量向量差范数 ≤max(1e-4 N·s, 参考冲量范数5%)。同时检查角冲量平衡、有限性及原碰撞保护。不得为获得提速放宽门槛。
5. 固定同一机器、线程配置和工作量，预热后至少三组交替计时。分别报告求解器与 Isaac 整机耗时，不以局部优化倍数代替实时率。
