# Tripod精化接触避免未使用粗算
目标是在既有Teacher执行链内去掉已证明不参与最终决策的重复几何计算，不改变物理/成功/安全合同。
独立只读复核建议复用check_supported_shape既有tube=None语义：仅target=True且已强制注册连续精化、.00015m原上限的调用传None。
非target继续原archived_tube；共享脚本、连续证书、SDF、USD与封存Reset源码均不修改。不新增算法开关或模块。
以已有真实SDF/SDK形状CPU用例验证精化仍执行，粗算仅保留非target；旧实现先失败。
随后以原始v9八/六十四帧数据交替比较完整geometry packet与失败原因，测量真实收益。CPU数据复放不得写为新原生或抓取成功。
本包属于用户已批准的现有执行链小包修复；按持续自主授权实施，原生预算不自动扩大。
