# 双手参照右手对捏

用户看到记录回放后，指出左手圆杆深入掌内，并要求双手都采用截图中的右手方式。本次是已有原生多点搜索设计的参考姿态修正：保留不固定目标力、允许改变手指和手掌朝向、原12主动+10从动及原执行器限幅。

使用C/case35右手的实际link位姿、圆杆位姿及源USD作为参考。先检查右手闭合几何在原桌面物体高度是否可行，再关于圆杆中心Y反射其参考点。反射后的点由左手自身FK与合法刚体旋转拟合，不能将反射矩阵当作旋转，也不能直接照抄两手关节角。匹配拇指/食指与手体外形，完整检查手入杆、杆入手、非相邻自碰和桌面间隙，避免用掌内包埋换取接触。

预抓姿阈值沿用0.3mm穿透和0.3mm桌面间隙。闭合保持通过原物理驱动执行，目标力为空，无外力、附着或正常物理运动的位姿传送。实际底部离桌30mm且真实接触保持0.5秒后，仍须复核全过程穿透，才能称为合格教师。几何或物理失败如实保存；展示窗口明确区分实际仿真与历史记录回放，不自动启动PPO。

实际复核发现圆杆轴向滚转不应成为手掌的参考姿态；采用由杆长轴及重力方向定义的无轴向滚转坐标系。原食指预定义patch偏离实际接触，改用完整末节凸包最近表面点，整个手体仍检查碰撞。

固定微闭合对照未形成持续双指接触，故诊断入口使用逐指接触存在性反馈：仅主动索引1/2/7/8补闭合，接触低于0.1N时以0.02rad/s缓慢闭合，已接触则保持，实测该指几何陷入超过0.8mm时退让。0.1N仅为接触判别，不是期望力或力上限；原主动角度/速度/扭矩限幅保留。几何按60Hz测量、输入采用前8个原始物理步的实际负载均值；原始480Hz读数保持不改。提升仍按时间独立执行，无新的lift准入要求。闭合搜索在seed附近受限，避免重新卷入掌内；该控制只在显式诊断进程启用，普通PPO入口不变。
