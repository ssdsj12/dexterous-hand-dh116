# DH116 自由夹持 PPO 修改方案

状态：用户已于 2026-10-25 确认；按此设计实施。

## 目标与既定要求

保持当前刚体 rough_rod、物体原位置、DH116 资产和力矩上限。从 close 初始化，PPO 学习手指闭合，允许不同手指及指节形成夹持，不要求四个指定指垫同时接触。成功仍按物体离桌至少 30 mm、保持 0.5 s、受限滑移判定。保留 20 维动作类别：12 个主动关节、双手 XYZ 微调、双手目标夹持载荷。

## 本次核实的事实

- `tabletop_gpu_isaac.py` 只测量双手 finger14_link、finger23_link 四路接触，已经过滤到 Wire；其他手指的碰撞存在，但没有纳入这些接触信号。
- `tabletop_batched_task.py` 与 `tabletop_force_feedback.py` 都把四路信号分成每手两路，供力反馈、close/hold 和 lift 门控使用。因此只改奖励不能解决接触覆盖问题。
- 默认指令是参考关节角附近 ±0.08 rad，叠加有界力反馈后限制在 ±0.15 rad；限速 0.05 rad/s。是否足以闭合需要实际可达性验证，不能仅凭范围小就宣称它是失败根因。
- v71 的 2048 环境运行已经停止。monitor 记录 633856 samples、updates=16；env 61 的耦合误差达到 0.0221036859 rad，触发 mimic_error 和全局物理安全停机。物理根因尚未复现，不能用增大阈值掩盖。
- 旧 checkpoint 校验完整合同。新增观测或改变动作映射不能作为同一合同的原地续训。

## 方案比较

1. 推荐：完成接触信号、闭合可达性和停机原因修复，再启动新版本 PPO。获得真实成功短轨迹后可用于示范预训练；成功示范不是允许开始 PPO 的前提。
2. 仅修改接触奖励：改动小，但力反馈与阶段门控仍忽略其他指节，不满足自由夹持要求。
3. 先构建完整示教学习系统：可利用成功动作，但当前没有经验证的 DH116 示范库，会扩大范围并推迟 PPO。留作独立后续工作。

## 推荐方案的模块与数据流

### A. 全手物体接触

为双手各个带碰撞的物理 link 建立物体过滤的测量映射，包含指节与手掌，不按 mesh 重复统计同一刚体。保留原四路 `pad_forces_n` 的语义与诊断输出。

新增按 link、按手指/手掌分组和按手汇总的物体法向接触载荷。分组顺序、单位、归一化和版本写入合同；缺失测量必须报错，不能填零冒充真实测量。接触载荷是法向载荷统计，不称作物体净支撑力或完整接触力矩。

数据流：物体过滤接触 → 确定性 link 映射 → 分组载荷/单手载荷 → 策略观测、力反馈、阶段门控及奖励。新增分组载荷观测，旧四指垫诊断继续保留。不能把全手数据硬塞进四槽来伪装 checkpoint 兼容。

### B. 夹稳门控与奖励

力反馈、close/hold 和 lift 门控统一消费新增单手物体载荷，允许每手采用任意有效接触组合；双手协调任务仍要求双手参与，不约束具体哪根手指接触。

保留接触势能进展奖励：全手物体载荷总和 0–10 N 线性映射到 0–5，实际奖励使用相邻状态之差。触桌、手间或自身接触不计正接触奖励。保留实际提升、稳定保持、滑移惩罚、动作平滑和终止项。单 link 过力检查扩展到所有受测 link，不能用全手合计替代局部过力检查。

接触力大不等于已夹稳。阶段转换仍结合速度、滑移和持续时间；物体实际离桌和保持才算成功。

### C. 闭合范围与耦合错误

先在原合同下定位 env 61 的耦合异常，收集主动/从动关节位置、指令、误差、接触、控制阻断状态，验证源头。保留原阈值，按复现结果修正控制或物理实现。此次设计不预先认定根因，不直接取消全局安全停机。

建立同一刚体、同一摆放下的可达性诊断，检查各主动关节在合法耦合范围内是否能够从 close 初态达到接触、继续闭合和释放。新指令映射使用逐关节开放/闭合边界，限制在合法范围；边界由几何与加载验证确定，启动时写入版本化配置，不在正式训练中自动漂移。保留速率、净空、耦合与过力保护。不会一律增大力矩或把所有关节直接放开到全行程。

### D. 训练迁移与短示范

推荐为新接触观测和动作合同启动新 PPO，保留旧模型作对照；旧训练步数、optimizer 和每环境完成回合数不算作新任务进度。首选仍是 2048 环境、每环境 1024 回合，在新增接触测量后重新验证显存和吞吐；容量不满足时按实测降低，不能以占满显存为目标。

先完成小规模物理与复位验证，再运行目标规模。若诊断或 PPO 自然得到成功短轨迹，保存观测、动作、接触与验收结果；未来的示范预训练仅使用通过完整验收的轨迹。当前版本不将“先找到成功示范”设置为训练准入条件，也不把人工固定闭合回放标作 PPO 已学会。

## 验证与验收

1. 离线测试：非指定指节接触被计入；桌面接触被排除；每 link 不重复；scalar/GPU batch 汇总、门控和奖励一致；旧合同明确拒绝误加载；新映射与耦合/限速保护一致。
2. 单实例 Isaac：用同一个仿真实例顺序验证接触来源、闭合/释放、复位和耦合异常复现。遵守单核单线程、不同时开第二个 Isaac。
3. 目标规模：观测和策略参数有限、实际优化更新发生、回合正常终止和复位、物理异常可定位；全部测试结果单独记录。
4. 抓取验收：真实物体高度、连续保持时间和滑移满足标准；训练启动与抓取成功分别报告，不能混称达标。

## 设计自查与待确认点

目标、物体、动作类别和成功标准沿用已确认要求。未知的是耦合异常根因与可达闭合边界，以上给出实测确定方法，不提供虚构标定值。接触与动作合同一起变化，因此建议新建训练而非静默续训。此次待用户确认的具体方案是：采用方案 1，按新合同重训；暂不将完整示教预训练系统纳入本轮。
