# 抓取控制对照验证

用户已确认：先验证控制，再调整奖励；本设计记录已确认的试验范围。

## 问题与目标

v134 在第 527 轮仍未成功离桌，758 次 close→lift 中 757 次触发向下瞬发惩罚。最近 50 轮只有约 0.176% 的 lift 物理步允许上升。必须区分奖励学习问题、接触几何问题与控制条件阻塞，不能用加大奖励替代控制验证。

## 已确定的选择

采用小规模同物理参数试验；不采用只改奖励或未经测量直接改抓点。保留 480 Hz 物理、60 Hz 控制、原始材料、0.12 kg 刚体、关节及过力保护、close→lift 条件、原奖励。保存训练检查点后停止训练 Isaac；同时只能运行一个 Isaac 实例。旧 run 与检查点保留。

8 个环境：2 个当前检查点的确定性策略基线，6 个固定动作组，分别为每手目标 4/8/12 N × 手掌 z 动作偏移 0/−1 mm。每个环境采集前 3 个完整回合；额外回合不进入报告。固定动作以初始化文件中的 grasp_command 为关节目标，经现有动作映射、力反馈和速度限制执行，绝不直接写实际接触力。z 偏移是策略目标分量，实际位置仍受力反馈补偿、净空及移动门控约束，报告实际位移。

## 实现边界

在现有 tensor pipeline 中增加显式诊断入口。只加载策略权重、不更新优化器；允许检查点与诊断配置仅 num_envs 不同（8 环境保持原 minibatches=8），其他契约必须一致。正常训练分支保持原行为。

添加默认关闭的逐物理步观察回调，在任务判定后、物理复位前采样。记录阶段、回合编号、终止原因、实际底面高度、速度、滑移、每手载荷/目标力、法向及摩擦竖直分量、关节实测与命令、手掌偏移、提升命令、各门控及其交集。区分门控使用的前一时刻测量与执行后测量，避免错误归因。逐 link 接触力与 link 位置可以作为定位证据；若不能获得真实接触点，必须标注 link/标定 pad 位置仅是代理，不声称已测出接触点。

保存压缩原始轨迹、逐回合摘要、检查点来源及配置差异。诊断不写训练检查点。fatal guard 触发即停止，并保存可用轨迹；普通任务失败沿用原复位机制。预算上限为 3×15 秒再加 2 秒仿真余量，不无限运行。

## 验收与后续决策

初步可达：实际底面离桌至少 3 mm 连续 0.1 秒，且已有有效夹持（原载荷条件）、物体速度小于 0.03 m/s、滑移不超过 0.02 m。最终成功沿用离桌 30 mm 稳定 0.5 秒。不将进入 lift、指令高度或瞬时冲击算成功。

若固定动作能成功而策略失败，之后设计有上限夹持奖励；若固定动作均失败，优先定位载荷不足/过载、关节耦合或位置约束。有限组试验失败只证明本组未成功，不证明任务物理不可达。不得自动放宽保护或改写用户要求的瞬发 −3。试验结束后按结果处理控制问题；无须改训练配置时，从保存检查点恢复训练。

## 验证

CPU 测试覆盖动作反映射、目标力编码、只允许环境数差异的契约检查、终止样本的采集与回合上限、真实高度持续判定。实际 Isaac 运行验证全部 8 环境、每环境 3 回合及现有 guard。报告明确区分离线通过、仿真执行与真实离桌成功。
