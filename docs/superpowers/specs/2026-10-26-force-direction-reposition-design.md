# DH116 受力方向闭环与从零 PPO 训练设计

## 目标

解决双 DH116 手抓取刚性圆柱时，手到物体的竖直合力长期为负的问题。当前控制器只等待手部接触载荷下降后移动，不能确认物体竖直下压力已经释放；新控制器必须先松开，再下移抓取点，再重新夹持，并从全新 PPO 状态开始训练。

## 现状与边界

当前 `v159_release_reposition_ppo4096` 仍使用 `release_reposition_reclose_v1`。它以 PPO 的向下掌部请求和手部载荷触发调整，尚未使用竖直合力作为释放条件。新版本保留现有 DH116 关节、力矩、摩擦、物体质量、桌面净空和物理安全上限；只改变 close 阶段的受力方向闭环和训练启动方式。lift 阶段不做抓取点重定位。

## 控制器设计

每只手维护 `normal → release → move_down → reclose → normal` 状态机。

- 进入调整：close 阶段，当前手载荷大于 0.1 N，且该手或双手合成的物体竖直力低于 −0.15 N。
- release：降低拇指和食指接触目标。只有手部载荷不高于 0.05 N、物体竖直力不低于 −0.05 N，并连续保持 0.05 s，才允许移动。
- move_down：沿世界 Z 轴向下移动抓取点，单次最大 2 mm，受现有桌面净空和 driven carriage 速度限制。移动中若载荷重新超过 0.05 N 或竖直力低于 −0.15 N，立即返回 release。
- reclose：重新建立至少 0.1 N 的手部接触载荷，并要求竖直力不低于 −0.15 N 连续 0.05 s，才回到 normal。
- 每只手最多尝试两次。松开、移动或重新夹持超时则记录对应失败原因；两次失败后结束该回合的调整。
- 只释放产生主要负向竖直力的手；两手均负向时同时释放。另一只手在单手调整期间保持夹持。
- lift 阶段禁止该状态机介入。

## 数据流

Isaac 接触传感器提供每手竖直接触分量。控制器使用与现有 `hand → object` 世界坐标定义一致的信号，并排除桌面和另一只手的接触。任务层继续使用双手合成竖直力计算奖励和 TensorBoard 指标；控制器额外使用每手分量选择释放对象。

新增状态和诊断字段：当前状态、尝试次数、松开前/后竖直力、移动中竖直力、重新夹持后竖直力、松开超时、移动重接触、重新夹持超时、目标裁剪和实际完成次数。所有字段按环境写入 TensorBoard 和 episode JSON。

## 奖励与训练

第一阶段不改变现有奖励权重，先用控制探针验证受力方向闭环。保持向上力奖励、向下力惩罚、close 完成瞬时 −3 惩罚、真实离桌和稳定保持成功奖励的现有定义。只有控制探针证明负向竖直力下降后，才单独调整奖励权重。

新 PPO 从零开始，不加载 v159 或任何旧策略/优化器状态。旧 runs 保留；新 run 使用独立目录和独立 TensorBoard 日志，不与 6008 合并。训练规模先按 4096 环境、24 rollout steps、480 Hz 运行；探针阶段使用 8 和 16 环境。

## 验证与失败处理

1. 运行 8 环境无 PPO 控制探针，必须观察到 release → move_down → reclose 顺序，且移动前满足双条件。
2. 运行 16 环境扰动探针，检查负向竖直力、误松开、状态振荡、桌面净空、超力和 NaN。
3. 通过后从零启动新 PPO，并打开只指向新 run 的 TensorBoard。
4. 若出现穿桌、超力、非有限状态、状态机循环或训练进程退出，立即停止并修正；无异常不介入。
5. 成功仍以物体真实离桌至少 30 mm 并稳定保持 0.5 s 为准；控制器受力改善不等同于抓取成功。

## 交付物

- 受力方向闭环控制器及单元测试。
- 8/16 环境探针报告和 episode 级受力曲线。
- 从零 PPO run、启动记录、检查点和独立 TensorBoard 地址。
- TensorBoard 至少包含 `force_N/*`、`reposition/*`、`phase/*`、`lift_gates/*` 和奖励分项。
