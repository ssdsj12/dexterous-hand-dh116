# Live Teacher wire feedback diagnostics

The owned collector can now record one episode of palm geometry and previous-window reaction data in an independent journal. The actual worker selects this diagnostic for the existing Tripod contact profile. Smoke workers retain their prior journal and policy input contract. The diagnostic changes neither 24D action execution nor the reward, optimizer, checkpoint or success thresholds.

The reader takes unnormalized palm World poses from the mounted SDK source packets. On the first decision, it chooses one measured material node per hand from that hand's half of the wire and fixes those references for the episode. It records the current palm-local geometry with all reaction-validity entries false. The priming exchange never enters a policy window. Subsequent decisions verify the same episode and policy index, current rod nodes and both World palm poses against the preceding completed exchange. The pose comparison converts the raw WXYZ quaternion to XYZW and permits the equivalent opposite sign.

After the original durable physical recorder and reward observer succeed, the trace owns the current window's exchange buffers. A complete bootstrap record can be matched with the next pre-action digest. A terminal partial window produces no bootstrap feedback. A truncated full window can yield a final diagnostic bootstrap. Terminal, invalid or closed collectors discard history. Episode changes require a fresh attachment. A rejected diagnostic sample is logged without forwarding a replacement measurement to the Actor. The Actor continues to use its original inputs.
