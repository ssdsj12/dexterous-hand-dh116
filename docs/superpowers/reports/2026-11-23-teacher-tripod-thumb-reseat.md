# Tripod thumb re-seat during index closure

The opt-in `--thumb-reseat` diagnostic holds index and thumb joint targets when the previous completed solver interval loses continuous thumb contact. At the next original 60 Hz boundary it can propose a wrist-only left translation of at most 10 µm per SDK step. The direction follows the current registered thumb SDF gradient, with no change to the right target or original action contract. The original SDK substep selector still permits only the proposed 24D increment or zero. It returns zero when thumb coverage is restored, the SDF improvement is lost, or the original wrist projection and contact envelope cannot pass. Index closure resumes at a later original control boundary.

This is a re-seat diagnostic. It detects actual reaction coverage and does not use predicted depth or pose as a grasp-success label. Existing table, supports, distal station, source and cooked hull, joint tracking and reaction-delivery checks remain active. No correction is attempted after first left index contact. The current control-window and overall native budget do not expand. Re-seat windows count against the existing close budget and are recorded separately. This isolates the first correction without granting extra physical steps for index closure.

In an offline replay of the 9 mm physical episode, at the next 60 Hz decision after load loss (SDK 3210), the production proposal function reduced the static measured-geometry SDF estimate from +8.97 µm to −1.27 µm. The original wrist projector admitted the command, and all 44 reconstructed hulls passed the original one-step checks with a minimum rod margin of 24.76 µm. The registered reference poses agreed with FK within 0.074 µm and 0.955 µrad. Unrecorded links use source FK and measured joints, so the replay cannot qualify native dynamics. Later stored states show that correcting only after index contact would increase its SDF gap.

The next native diagnostic stays on the 9 mm specimen. It checks which SDK steps issue re-seat commands and whether thumb and index actually load and oppose within the same solver interval. A previously loaded thumb, isolated index touch or clean native exit cannot qualify Lift. The qualification remains 30 mm net Lift, 5 s Hold and ≤0.5 mm slip for each grasp and held-out physical specification.

The corrected loop finished at SDK 3298 with 39552 solver substeps in 765.13 seconds. It exited naturally with code 0. All 6332 artifact hashes and the ownership and reaction clocks were verified. A one-time stale pre-launch fingerprint was refused before Isaac started. Its budget was unconsumed.

The minimum predicted hull reserve was 1.00 µm. During index closure the thumb had positive load in all 12 substeps on 41 of 88 SDK steps, up from 8 of 88 on the same wire without re-seat. The first full load after the initial loss came from the actual solver. The hold phase still had no fully loaded thumb interval.

Five windows were spent on re-seat. The observed index rotation from the start of the pivot was 0.01662 rad, compared with 0.04946 rad on the fixed-wrist run. The terminal left index SDF gap was 2.817 mm. It had zero load, so there were zero thumb/index opposition intervals and no Lift. This evidence supports feedback-based wrist adjustment. It also shows that alternating entirely between re-seat and index closure uses too much of the existing closure window. The next experiment should measure joint progress and retain thumb contact through closure and hold before advancing toward middle-finger contact or Lift.
