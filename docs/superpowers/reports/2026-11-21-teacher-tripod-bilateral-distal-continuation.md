# Tripod 保留右手载荷并加入左手三指的分段方案

直线连接左手原生末姿与三指近接触姿态时，非目标指节会侵入线缆包络。独立求得的中间路点先收开部分手指、转动掌根，再把三指送入原材料位置。复核 SDK 752 的右侧真实接触和下发反力，与该原生归档完全相同时才允许开启左侧目标指形状。增加 68 个控制窗，右半 12 个通道严格为零增量，保持上次有效命令目标。

两段各 17 个位置的全手 CPU 复核给出非目标包络最小杆间隙左 0.940 mm、右 1.067 mm。左目标拇指、食指、中指末端 SDF 约 −0.070 mm，点积 −0.871 / −0.573。为排除左指姿态滞后，进入第二段前先静置 8 窗，且掌位置、旋转、主动关节误差分别必须在 0.20 mm、0.008 rad、0.0025 rad 内。原全手桌面、支架、非目标杆及关节保护均开启。真实目标接触及后续反力、左右手同时达标的持续时间单独逐行记录。

156 项 CPU 回归通过。单实例预算 1296 SDK 步、132 控制窗、15528 求解器子步、600 秒软上限、零 PPO。入口 `python -B -m scripts.verify_dh116_tripod_supported_reset --bilateral-reference PRIOR --bilateral-screen PROOF …`。几何通过仅允许试验，不确认抓稳、离架或 Teacher 准入。
