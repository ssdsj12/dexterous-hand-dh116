# Pinch 左食指先行与右腕追平

Antigravity 建议在 SDK58 继续等待右腕追平，并给左手预接近。复核实测原始指垫发现 SDK58 左拇指与食指分别距杆约 0.61/2.31 mm。原方案同步合指会让左拇指提前加载。仅保持右手旧目标的全指几何盒也未能证明右拇指间隙。改用左食指先行，首窗将右拇指和食指目标撤至 SDK58 实测值，随后右腕留在原目标追平。

`run_dh116_pinch_index_pacing.py` 复用自然退出的原生 SDK58 前缀，附加 6 个 60 Hz 窗。新几何校验独立考虑拇指、食指与腕平移 XYZ／内禀转角 XYZ 的旧目标和新目标组合。左侧证书包括全部指垫，右侧含桌面及非目标杆净空。两个方向都继续通过实际求解器 pair 检测任何手杆接触，并保持原物理安全守卫。这个证书的结论限于条件跟踪盒。

| 实测量 | SDK58 | SDK106 |
| --- | ---: | ---: |
| 左食指关节 | 0.677318 rad | 0.699664 rad |
| 左食指估计指垫间隙 | 2.311 mm | 0.794 mm |
| 左拇指估计指垫间隙 | 0.612 mm | 0.611 mm |
| 右腕实测 pitch | 7.720 mrad | 13.713 mrad |
| 右腕目标 pitch | 17.198 mrad | 17.198 mrad |

现场两侧各 22 个凸包通过，最低条件余量左 81.56 µm、右 8.96 µm。104 个测量物理步、1248 个求解器子步、13 个完整控制窗。杆节点最大位移 7.45 nm，实际账本有桌面 pair 51,168 条、手杆 pair 0 条。外层在 114.7 秒自然退出 0。这里的指垫间隙通过同钟实测位姿及 SDF 估计，后续对向受力仍由实际 pair 核验。未建立接触、抬升或训练。

首次配方在 AppLauncher 之前因离线证书需要导入 USD 被拒绝，未启动仿真，保留 `ag2170-index-pacing-native/outer.json`。修复版把归档几何预检限于冻结计划的 CPU 子进程，原生启动仍核对同一配方，场景启动后在 SDK58 对当次读回复算。212 项工作包 CPU 回归通过。
