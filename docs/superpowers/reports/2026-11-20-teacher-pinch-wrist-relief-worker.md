# Pinch 左腕减切向运动对照准备

Antigravity 核对 `8dff5ff` 后推荐单独测试左腕。原生左拇指反力翻转前后的原始接触对来自杆节点 35/34。同一个拇指局部见证点用两个连续的 SDK 指腹位姿回算，结合节点速度，SDK73 的切向相对速度代理约为 **[2.192, 2.645, −11.510] mm/s**。其沿节点局部切线的投影约 2.62 mm/s，主分量来自接触平面内的另一方向。因此本对照围绕左食指的见证点微转腕目标，抵消所测拇指切向分量的一部分。跨 SDK 的速度代理用于选方向，不能解析求解器子步间的运动或归因于摩擦模型。

保留早闭合参考的双侧全部指令与右腕，动作表仅改变 SDK58–74 末两个完整 60 Hz 窗的左腕六项。通过纯世界旋转及补偿根平移保持名义食指见证点。编译沿用原平移/旋转速率球，加入平移约 [−65.05, −88.07, +97.23] µm、腕内禀 XYZ 约 [+0.254, −0.842, −0.472] mrad。实际原生动作前需先通过 SDK34 早闭合门，再通过 SDK58 同钟双手、节点与腕姿读回；提前保护停机继续写完可核验账本。

CPU 筛选覆盖 SDK58–74 的 17 个历史实际边界，额外平移与旋转增量分别考虑独立 0–100% 跟踪，杆节点加入 50 µm 敏感性。非目标间隙下界 0.0304 mm，桌面间隙下界 2.596 mm，末帧名义左拇指/食指 −4.83/−12.63 µm。每个盒使用固定的实测手指关节与相应历史快照。值不代表帧间动态、未来杆运动保证或真实反力结果。0.0015 rad 的预扫异步盒在近端检查中无正余量，选 0.001 rad 的干预。

171 项相关 CPU 回归通过，独立 Python 进程通过 Isaac 前干净导入边界。冻结执行为一次、单实例 GPU2/1 环境、至多 74 SDK 步和 864 求解器子步、零抬升、Teacher 或 PPO。结果以独立重读的双侧有符号同时承载为准。Tripod 的实测无接触跟踪对照提示弯杆近端优先扩大拇指 `finger13_link` 与中指 `finger32_link` 的安全余量，现有数据仍不足以带受载晋级。
