# DH116 三抓法 Teacher 接触与状态来源复审

以 Ubuntu 和 GitHub `11-17` 的 `bcfd5171187ff5c2b955cbe2f52e830c95d70b1c` 为基线。Antigravity 通过只读 SSH 核对了源码文件 SHA，随后复审三指判据、模型输入账本和 Reset 的封存／生产读取差异。首个 Argon 请求因模型不可用被取消，Hydrogen 完成了三轮审查。Codex 独立追踪调用链并复现测试。经追问确认封存脚本与生产读取器的退出码检查范围不同。

## Pinch 模型输入

`NativePinchSources.pack_recorded` 保留实际单次模型打包收到的 pre-action 状态、原始 41 节点、原始参数、任务 context 和返回的六个模型张量。每一组输入附独立 SHA-256、scope、物理时刻和账本序号。记录发生在成功打包后。Collector 通过序号将动作决策和 Reset 前价值估计分别绑定到各自输入。动作前因相机或预算放弃的记录缺少动作决策关联，不能作为 PPO transition。实际采样与执行仍走原策略、原 24D 命令、原控制器。日志仍使用原边界的作用域，`native_qualification=false`。

## Tripod 反作用力

过去对任意一对指腹检查夹角，再对第三指取绝对投影。这在四个新反例中误判了双侧任一指向错误的样本，也在双手各 120° 的对称布局中误拒了有效对向。现用拇指与食、中指平均法向构造共同轴，并分别检查拇指与食指、拇指与中指的点积。两个食、中指需要落在拇指对面的有符号投影半面。原点积、投影与载荷数值阈值保持。有限的对向余量取两对较弱的那一对，以保留既有字段形状。此判据服务于现有力闭合诊断。Tripod PPO 仍需要双手同钟测距、接触来源和独立 Reset。

## Power 与新 Reset

Power 的五指加载检查保留。旧 13 mesh 账本只有十个 distal 指腹、桌面和两个支架，仍缺实际掌面或近端反作用力以及包覆的证据。历史回放和人手姿态均不授予 Power 训练资格。

新 Reset 的生产读取器现在在读取数值数据前检查同抓法外层退出必须为整数 0。带已重算 SHA 的 −11、缺失、false 和 0.0 均被拒绝。原生诊断留下的真实 Pinch 数值 Reset manifest `110f6dbcca61f36111ada20c47dbf698fab72fe2cef4d8e36c866690b4531daa` 通过。已锁定的历史 Pinch R08 路径继续使用原校验。还需要实际 `run_a`、worker 来源和独立产物审计，才能做首轮真实 PPO。

## OakInk 接入边界

[OakInk 官方仓库](https://github.com/oakink/OakInk) 包含 OakInk-Shape 的人手抓取姿态和物体模型，以及 OakInk-Image 的 MANO 关节、物体姿态和相机参数。可以抽取与线缆直径接近的细长物体，先在物体局部坐标比较拇指与其余手指，再用 DH116 FK、主动关节限位、mimic 联动和原碰撞几何做两手分别重定向。Pinch 可作为张开和两指对准候选，Tripod 候选保留拇指与食中双对向，Power 候选保留掌面朝向与五指闭合。按对象、原始主体和来源划分数据，姿态只进入独立候选初态清单。原生反力、模仿动作与成功标签都由 DH116 原生执行重新测量。采用前单独核对数据与 MANO 的许可及标注访问条款。此次没有下载或导入数据。可另评估 [OakInk2](https://oakink.net/v2/) 的双手运动参考，继续按外部候选姿态的用途管理。研究进度以独立 DH116 原生回执为准。
