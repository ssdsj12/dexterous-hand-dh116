# TASK 1：线缆深度交集与实测表面采样

前视 640×480 的旧记录显示二指／三指各有 4／9 个有效 token。逐像素参考复核显示这 13 个 token 都超过 5 mm 三维误差。既有 Roll20 Block5 采集具有更丰富的边缘匹配证据，同一批 RGB 经独立实验配置重放后，两种抓法各得到 32 个实测表面 token，分别有 31／30 个满足 5 mm 三维误差。该结果来自两个初态的离线重放，正式相机与 Student 资格仍待验证。

复核发现 wire 候选的亚像素精修是可选步骤。有效整数候选后来被右侧一致性拒绝时，旧诊断会优先归为亚像素拒绝。新增回归固定该顺序，精修使用情况单独记录为 `optional_refinement_used`。两套捕获再次重放均 exit 0。与 [第一次像素证据包](../../../artifacts/stereo-reliability-20261111/wire/per_frame_pixel_maps_ribbon3.tar.gz) 对比，56 份图的掩码、点位置、XYZ、深度及视差逐元素完全一致，NaN 位置相同。当前原生捕获中的候选都在更早的门槛拒绝，首拒绝编码也未改变。

## 失败位置

前视的两个抓法逐帧掩码计数相同。下表交集各自以 RGB 候选为集合，LR 与深度范围两列为独立交集。

|二指|2377|96|165|195|6|4|

二指深度无效候选的主要首拒绝为低纹理 1083、亚像素 913、右支持缺失 191。三指分别为 1137、764、166。有效深度到骨架后再损失 90／61 个支持像素。原生实例参考显示，二指 RGB 候选精度 89.52%，三指 100%。二指／三指原生线缆 ROI 内 162／173 个像素的 5×5 左窗口触及已解析手指。前视基线 96／75 个有效线缆深度中 70／63 个窗口触及手指，而且基线最终 4／9 个 token 均来自这类窗口。原生右光轴 Z 重投影还记录 61／27 个更近遮挡样本。右图实例标签缺失，因此该数量仅作为右侧遮挡代理，不能逐像素判定右手指身份。

在联合可见暖色区只比较亮度纹理时，两个抓法大面积窗口缺纹理。新 `wire_census` 和 `wire_zncc` 对这些窗口保持无效，两套捕获都得到 0 个 token。Roll20 轮廓候选在逐像素深度层有 654／702 个有效，614／661 个正确，MAE 2.980／2.971 mm。严格沿骨架采样时仍没有有效 token，说明可靠深度集中在轮廓而非骨架内部。

## 运行改动与逐帧对照

`StereoDepth` 增加三个独立 opt-in 方法。Census/ZNCC 只比较左右 RGB 暖色候选的共同有效支持，保留绝对代价、非相邻假设唯一性、反向一致性与深度范围检查。轮廓方法要求实际双视图窗口、前景／背景边界和唯一整数候选。重复水平轮廓无唯一候选时保持缺失。所有方法都只从 RGB 与标定推导深度。

现有 `TrackedWirePointExtractor` 可选 `observed_ribbon`。仍使用最多 128 槽，96 槽保留骨架采样，32 槽用于可见 RGB 分量内、距离骨架最多 1–3 步的实测表面。走访只穿过 RGB 候选像素，从原有深度有效且有限的像素提取 XYZ，保留原骨架缺深度槽的 NaN。表面 token 有独立来源编码，弧长、切向和材料身份保持未知。运行时和独立推理都读取同一处理合同；推理重置时保留配置。新增独立 Roll20 silhouette+ribbon3 配置，默认处理模式不变。
