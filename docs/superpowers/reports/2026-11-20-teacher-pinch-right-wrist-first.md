# Pinch 右腕转角、平移和合指分阶段预检

Antigravity 核对 `dac6a21` 与原始指腕目标积分，确认指命令置零会继续保留既有 SDK 目标。独立核对 SDK58 右拇指和食指的旧目标超前约 3.713/5.209 mrad。先把这两段旧指目标算入腕部阶段的独立几何盒，而不是把测量姿态当作静止指令目标。

尝试把腕平移和转角一并从 SDK58 进入持握候选时，右近端 `source:finger13_link` 的桌面下界收紧至零，规定预算内留下未决域。SDK50 的对照也无法通过完整盒验证。保留两次结果，在原 24D 合同下将执行顺序拆为三个阶段。

1. 先只回调右腕内禀 XYZ 角。保持已有的腕平移目标和右指目标，证书覆盖尚未消化的右腕角及手指目标。
2. 右腕实测旋转达到条件区间后执行独立的平移窗。平移目标取计划路径的 65%，为右近端保留桌面净空。
3. 实测腕平移与旋转均达至少 55% 路径进度，并处于核验的允许区间后，才允许下发右指闭合。保持同一原平移和转角目标。

`prepare_dh116_pinch_wrist_first.py` 编译原速率动作，限制每阶段的非零动作通道。对每个阶段独立计算 22 个右手凸包的桌面及非目标杆证书，包含旧腕目标在名义轨迹外的剩余位移、非主指独立残差，以及 50 µm 杆节点敏感性。SDK58 指腕锚点分别结合 SDK58、66、74 原生杆快照评估，三阶段全通过。阶段 1 最小几何裕量约 0.034 µm，另两阶段最小约 0.616 µm 和 0.072 µm。名义右拇指间隙为 −0.064 至 −0.078 mm，食指为 −0.168 至 −0.066 mm。各测试以原 2.1 mm 桌面保护和原关节速率约束为准。

旧对照中 SDK58–74 全杆最大实测节点漂移约 0.824 mm。三个独立杆快照各自有 50 µm 的局部条件余量，不组成整段原生杆漂移的保证。下一步必须绑定新实例实际位置、目标、关节、杆节点、原始保护和每步终止证据，另行验证阶段切换和两手同时受力。当前输出无原生执行入口。

运行 `python -B -m scripts.prepare_dh116_pinch_wrist_first --archive <sealed_wrist_relief_native> --sdk 58 --rod-sdk 58 --output <new_receipt>`。另两份采用 `--rod-sdk 66`、`74`。192 项相关 CPU 回归通过。无新增 SDK 步、保持、Lift 或 PPO。

Power 源码独立审查定位到已有 F4 身份、坐标系和 CPU/GPU 拓扑等价校验可复用。现有循环覆盖五个指垫，掌面需要独立的 live cooked 左右读回。历史两侧掌面的 69.5/67.9 µm 平面包络超出来自单份历史 SDK 读回，未视为 CPU/GPU 等价。未加入掌面碰撞或 SDF。
