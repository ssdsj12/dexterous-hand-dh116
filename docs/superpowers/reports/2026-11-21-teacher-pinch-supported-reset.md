# Pinch 自由杆支架初态

用原生 Pinch 的实际接触节点与初态 PhysX 连杆位姿，分别把两只手沿原接触材料线段的方向变换到双支架自由杆。左手在变换后沿世界 Z 抬高 8 mm，右手沿 X/Z 分别偏移 1.5/1.0 mm。两侧主动关节角沿用原始 Reset 读回，每侧用自身的几何与材料节点。支架、重力、杆材、桌面与原 24D 动作合同沿用原配置。

| 239 个初始及已保存杆形的几何筛查 | 左手 | 右手 |
| --- | ---: | ---: |
| 保守手–杆最小间隙（mm） | 1.0639 | 1.0559 |
| 手–支架间隙（mm） | 23.9636 | 3.6401 |
| 手–桌面净空（mm） | 64.0284 | 59.6754 |
| 筛查几何个数 | 22 | 22 |

相关 94 项 CPU 回归通过。准备好的原生范围是 1 环境，2 SDK 初始化步、238 测量步、2856 求解器步、零控制及零 PPO，逐步验证仅支架反力与环境的自然退出。拟验证的是 Reset 和支架承托，接触、抓稳与抬升需要后续独立验收。

运行入口 `python -B -m scripts.verify_dh116_pinch_supported_reset`。冻结输入包含旧 Pinch 和自由杆实验回执、双方原生形状与现有 SDF、独立 Pinch 初态和完整几何筛查工件。
