# Pinch 与 Tripod 17 槽同钟真实反力判定

Antigravity 只读核对提交 2c19371，指出旧归约器的支架槽为 11/12，而完整 17 槽的 11/12 为左右掌，支架实际是 13/14。Codex 独立检查了代码与原始行。新入口先核对整个未过滤原生 pair buffer 与节点力、网格力矩、时间戳，之后复用原有 Pinch/Tripod 单垫和手载荷、三指共轴及对向阈值。另报支架与桌面每个子步的外部支持力、非目标连杆。旧 13 槽入口与 Power 原路径维持独立判定。

133 项 CPU 回归通过，覆盖不匹配网格、错误时钟、溢出、非目标力矩不符以及真实槽位。使用原封存 Pinch SDK 432、Tripod SDK 528 两条真实原生记录验证读取与归约。两例有效数据均检测到两端支架承托，无桌面载荷，无双手三指／二指对向。该归约可证明反力样本归属。仍需同一原生轨迹测量手与柔性杆的接触、真实传递至下一 PhysX 步以及离架抓取。

入口 `measure_supported_distal_contact(rod, grasp="pinch" 或 "tripod")`。归档回放新增原生步数为零。
