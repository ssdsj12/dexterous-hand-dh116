# 视觉 Student 右掌 Z 指令随 Checkpoint 的变化

在相同的原生 reset 观测上，二指和三指在第 1024 轮都已输出向下的右掌指令。两个独立派生模型的平均指令更负。与此同时，两更新训练中实际采样的指令均值向上移动。两种测量回答不同问题，前者固定了输入，后者还受到访问状态和探索噪声影响。

## 奖励相关性与训练阶段边界

单更新原生实验的 32,768 对 policy / action 记录已逐行核对环境、episode 和时间戳。二指、三指的右 Z 与联合 Advantage 的 Pearson r 分别为 −0.020876、−0.069233，与 Returns 的 r 分别为 0.014135、0.016747。在记录的 39 个奖励项中，有定义的相关系数按绝对值取最大，二指为 `dex_action_rate`（−0.035840），三指为 `dex_contact`（0.059029）。同一个环境的连续采样存在时间依赖，这些数值不足以解释偏置如何产生。

原始 1024 轮训练目录保留了最终模型。迭代日志和 TensorBoard 没有每轮的右 Z 动作分布。第 513 轮的物理 Lift 峰值不能还原当时的策略。因此目前最早能用权重直接确认负偏置的阶段是第 1024 轮；首次形成轮次仍未知。这项 CPU 比较没有运行物理 rollout，无法给出接触、净抬升或成功率的干预效应。
