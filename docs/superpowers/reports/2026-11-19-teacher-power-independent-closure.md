# Power 按掌面与五指角色筛查

本轮借鉴 OakInk 的物体局部抓取先验，把掌面与拇指、四指的作用分开。关节角由 DH116 本身的主动限位和 Mimic 合同计算，凸包使用原始 source 和锁定的 cooked 指腹。参考 [OakInk 数据说明](https://github.com/oakink/OakInk/blob/main/docs/datasets.md)。

新增 opt-in `--audit-closure`。沿已经通过固定关节平移扫掠的路径，在 0%、50%、100% 腕位分别筛查五个独立屈曲命令。原候选的输出与默认运行入口保持原定义。每腕位最多 35 个候选，分别记录首拒绝原因。闭合后的全手凸包重查桌面、端支架、线缆，另用保守分离轴核验拇指与另外四指。对每个腕位入选的候选再检查真实凸包近点、掌面对四指的几何方向、拇指对向以及双手分离。屏幕上的闭合姿态不能作为反作用力来源。

| 手 | 静态腕平移上限 mm | 排名最佳相对腕位 | 最大保守间隙上界 mm | 成对通过 |
| --- | ---: | ---: | ---: | --- |
| 左 | 19.5 | 0% | 17.332 | 0 |
| 右 | 14.5 | 0% | 16.972 | 0 |

全流程用两个端支架、同一根杆、材料工位左 33 和右 8。每侧三个腕位各 30 次独立几何评价，左右合计 180 次。最佳左/右候选的精确间隙上界最差分别为无名指 17.253 mm 和食指 16.972 mm。左腕位 0% 的掌面精确间隙上界 16.505 mm，右侧为 12.137 mm。右侧在该候选还未满足拇指对向点积 <−0.2。掌面对侧的四指几何方向可以建立，但距离仍超过原 0.5 mm 接触候选上限。较远腕位的最差指腹/掌面间隙更大。

## 复现与资格

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -B scripts/prepare_dh116_power_palm_seed.py \
  --end-supported --aligned-preshape --audit-approach --audit-closure \
  --left-node 33 --right-node 8 --output "$NEW_POWER_SCREEN"
```

首次完整命令退出 2，并成功保存未通过证据，SHA `80d9fa11b6ea28b3c86f61e18b7b276071d8845c1511fab2ab4509267b158fb1`。验收关注新目标应为改变腕姿与各指可达工作空间，使真实掌面和五指同时接近线缆，然后证实掌面、指腹反力、有界闭合及完全离架。原生运行 0、PPO 更新 0。13 项 CPU 回归通过，覆盖桌面、支架、拇指其余四指自碰保守筛查与同侧近点。

采用保守 AABB 快路径后的同一几何复算得到完全相同的六组排名、拒绝原因及静态判定。复算记录 SHA `8ad2029ca0c33de4c7b020378021ef1c15a9ba3f8c8aa75135e1d0dae33458a6`。关闭候选不成对时，新的 opt-in CLI 退出 2，并保留报告。
