# Pinch 右腕回调原生诊断

本次依据 Antigravity 的只读审查，把 SDK58 的原生测量接入右腕动作放行。CPU 历史证书只用于冻结候选动作。当前实例重新核对 SDK34 和 SDK58 的初态前缀，在当前杆节点及关节读回上重新验证右手 22 个凸包。右侧新动作只修改腕旋转，原有右指及腕平移目标继续由原控制器处理。左侧保持历史第八窗动作，实验在 SDK66 预算边界结束。其他腕平移、合指及抬升阶段需要另外验证。

原生使用一实例、一环境、GPU 2、单次、零模型查询、零 PPO。冻结指纹 `b70b01accef8504100332f24a3520cd73aced29a35343727a98120b61e2ee304`。上限 2 个初始化 SDK 步、8 个控制窗、768 个测量求解子步和 180 秒软墙钟。原几何、关节、安全阈值及物理频率仍由已有控制路径执行。

| SDK 步 | 最大杆节点位移（相对 SDK58） | 右腕 pitch 目标 | 右腕 pitch 实测 |
| --- | ---: | ---: | ---: |
| 58 | 0 µm | 22.029 mrad | 8.100 mrad |
| 59 | 35.554 µm | 21.425 mrad | 8.378 mrad |
| 60 | 72.122 µm | 20.822 mrad | 8.640 mrad |

SDK58 现场证明通过，22 个凸包最小条件裕量约 0.0344 µm。SDK60 第一次越过 50 µm 节点覆盖范围，终止原因 `pinch_angular_rod_reserve_exceeded`。探针在每个 SDK 步完成后监测杆漂移，保护发生在样本记录端。它没有预测两个采样边界之间的杆位移。保留 58 个测量步、696 个求解子步、七个整窗和最后一窗两步的证据，结算记录齐全。耗时 83.4 秒，`app.close` 正常返回，外层自然退出 1 表示诊断失败，未强制退出。

同初态历史窗口复读得到 SDK58–60 的 41 个杆节点坐标与本次逐点一致。SDK60 的左拇指载荷范围为 0.0398–0.0429 N，左食指和右侧两个 pad 在这三步内均无载荷。此对照说明右腕回调未改变这一段杆漂移，当前仍处于单侧拇指加载，且存在正向右腕跟踪惯性。SDK60 原路线右腕目标为 22.947 mrad、实际为 8.688 mrad，本次回调的目标和实测均小于原路线。本轮没有建立双侧对向接触、稳定保持或抬升。

下一步用相同初态诊断左拇指推杆和桌面/支座反力，计算合适的卸载或预载窗口。在任一新的放行动作前，分别验证未消化的左/右指腕目标和实际杆漂移，再推进行走、闭合和固定手腕。Tripod 的右手接触路径需覆盖实测拇指跟踪偏差。Power 的独立掌面 cooked 几何及双侧五指包络仍待验证。
