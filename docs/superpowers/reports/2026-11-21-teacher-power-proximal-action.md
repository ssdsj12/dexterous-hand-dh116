# Power 17 槽接入原 24D 动作链

在原生 17 槽 SDK 240 无接触静置回执上固定一窗原动作合同。仅在两个手腕的负 X 方向分别输入 −0.5，动作索引 12 和 15。按原 0.01 m/s 速率，8 个 SDK 步的目标位移上界约 83.3 µm。手指、腕旋转和其余平移输入保持零。

进入动作前逐项核对现场实测关节角、速度、目标、手部位姿、质心、净空、杆、支架和原接触布局，要求与封存的 SDK 240 记录一致。动作入口继续使用同一杆和两侧 Articulation，按名字核对每侧7个反力槽，逐步记录物理反馈。任何桌面或手部接触，或一个子步失去任一支架正常支撑，都会停止本次诊断。原 15 槽路径保留。

原生预检已冻结 2 初始化+238 静置+8 动作 SDK 步、2952 求解器子步、一次动作窗、零 PPO、180 秒软上限。命令在既有近开入口增加 `--proximal-action-reference`，输入为已核验的 17 槽回执。130 项 CPU 回归通过。此次尚无原生动作结果，下一阶段核验实际追踪、有序反力和自然退出。抓取资格仍待完整物理验收。
