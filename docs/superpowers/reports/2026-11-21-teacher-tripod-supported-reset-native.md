# Tripod 双手支撑初态原生验证

独立 Tripod 初始场景在实际 DH116 和 DeformX 求解器中完成 Reset。验证使用同一根无固定节点的自由杆，重力与材料沿用原参数，支架由原碰撞系统持有。全程记录两个支架和实际 DH116 关节状态、杆状态、每步时钟及逐对 wrench。

单 Isaac 在 71.61 秒内完成 2 个 SDK 初始化步、238 个测量步和 2856 个求解器子步。每个子步两端支架均有有效法向反力，各计 2856 条接触 pair。所有 17 槽中手和桌的 pair 均为零。初始 SDK 读回的最小手到支架间隙为 1.920 mm，左和右最低实测桌面净空分别 57.382 和 44.009 mm。对应 238 个原生时间点的杆节点位置、速度和静止长度与另一独立静置参考逐步相同。外层与 GDB 内层自然退出 0。

107 项 CPU 回归已随独立配方发布。原生执行入口 `python -m scripts.verify_dh116_tripod_supported_reset`。运行并未下发抓取或抬升动作，零 PPO。下一阶段使用本次原生初态记录，在相同物理边界逐步核验双手向线缆靠近，建立拇指、食指和中指的实际反力。
