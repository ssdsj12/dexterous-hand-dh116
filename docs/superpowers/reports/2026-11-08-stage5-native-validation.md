## T1：右 finger12 的可复现故障与有界保护

完整数据、逐指/被动联动及矩估算来源见[关节跟踪报告](2026-11-08-stage5-joint-tracking.md)。原始 M2 回放再次在 env 932 / 799 的物理步 252 / 256 触发右 finger12 下界保护。SDK 目标合法，实际角分别 −0.012651443 / −0.013072879 rad；目标减实测误差达到 0.052294935 / 0.055283752 rad。因此不能把这两次事件解释成“SDK 目标越界”。原样 schema v1 / v3 的 508 条共同记录，实际完整关节和两手 SDK 目标差均为零。

微扰映射正确并不排除受载跟踪失败。右被动 finger13 先接近自身下止点，随后主动 finger12 继续负向运动，仿真隐式力矩估算达到 +0.2 Nm；记录还存在接触法向矩、实际腕部运动及耦合残差。摩擦、拒接触及完整约束反力矩未独立解析，因此没有认定唯一力学根因。

独立单侧跟踪保护虽去掉原两次越限，却在 env 661 引入新的单 link 过载：前125物理步与原样完全一致，第126步只暂停左腕、右腕继续执行，第185步右拇指载荷为 30.014557 N，越过原30 N终止线。共同暂停双腕、保留全部手指请求的候选在同一步右拇指载荷为 6.252856 N。原手指 SDK 目标保持一致。

共同暂停候选的 1024 环境 ×256物理步窗口没有终止，但只覆盖 0.533333 s，不能记作1024个完整回合或抓取成功。候选默认关闭，只用于独立实验；原始失败与单侧保护失败证据均保留。目标取消采用实测腕位/角，原 SDK 速度、力矩、碰撞与终止保护仍继续执行；取消已排队目标不能描述成原目标序列完全不变。

## T2：左右独立 FK、Jacobian 与物理微扰

详见[物理映射报告](2026-11-08-stage5-physical-mapping.md)。两手分别读取实际 USD 关节树、实际轴、主动/被动耦合及 base pose，没有用理想镜像或经验系数替代右 finger12 轴。

完整重复探针为53种动作 ×8环境，每次四个policy步。全文件1696条逐手快照、424个带case的唯一物理episode身份。左右 FK 对 SDK 位置最大误差分别0.000354 / 0.000399 mm，原生快照解析/有限差分位置 Jacobian 最大误差分别3.675e−10 / 4.652e−10 m/rad。384次单维方向检查中380次方向正确，4次左中指负向动作受原下界限制静止，0次反向；右 finger12 正负方向各8/8正确。

四步微扰的左右 finger12 目标跟踪误差最大分别0.000172943 / 0.000172907 rad。这里的目标由实际提交表达式重建，独立 native target 缓存读回另见T1；来源不可混称。小幅无故障映射不能代替持续受载资格。

Adapter 合同固定两手 USD SHA、源码 SHA、主动关节名、耦合及旋转语义。现有 SDK chart 本来就是原24D world/seed语义，`decode → to_sdk` 为恒等回归；这不表示左右真实几何完全镜像，也不表示 M2 获得部署资格。

本合同的十二个手指通道是具名主动关节速度，不是指腹笛卡尔速度。因此没有用Jacobian伪逆或经验系数重新解释旧关节命令。两手独立FK/Jacobian用来核验实际几何和追踪误差；它们不能把非镜像的关节树变成严格镜像。若未来要输出指腹空间语义，需要另外建立并验证新合同，不能静默修改现有24D模型。

## T3 / T4：200初态配对干预与双手协调

四臂共用第四阶段200初态清单（二指/三指各100）、同一实际Checkpoint、seed和完整物理reset身份。Z0为M0原样；Z1冻结其余23维、只将物理索引17置零；Z2依据实际净空/相对物体高度与接触投影；Z3采用实际抓取点、COM静态纵向力矩分配，以及Lift/contact/slip/joint/sync协调目标。Z2/Z3为特权仿真控制实验，不能作为纯视觉Student成功。

Z3分配不强制50/50，使用实际抓取点与COM；它是纵向竖直平衡投影，不是完整六维接触扳手可行性证明。共同上升必须有实际双侧对向接触与正向归属支撑；跟踪/接触失效撤销排队上升目标。滑移取带同一episode/物理步身份的原生遥测包，避免成功观察器重置锚后误把漂移读成零。未知固定锚或无有效滑移读数记为未记录，不能补零。

完整配对统计在四臂自然完成后生成，逐trial保留掌心峰值的env_id、episode_id、physics_step和timestamp；不同环境峰值不拼成同一轨迹。
