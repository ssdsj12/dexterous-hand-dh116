# Power 原生 PhysX 掌面射线对照

在原关卡只读碰撞体上启用 Isaac Lab 的 scene query support，保留原 PhysX 碰撞体、帧率与关节合同。每轮只执行 2 个物理步，逐面心从外往内射线。只接受原掌 body 和对应碰撞路径的第一命中。被手指遮挡的射线保留身份与候选几何距离，排除出掌面误差统计。两次进程均自然退出 0。首轮没启用 scene query，138 条射线全部无命中，保留原失败回执。启用后左掌命中 56/68，右掌 60/70，余下 22 条首先命中原手指。

| 原掌 | 原扇面对 PhysX 绝对距离 P95 / 最大 | 凸顶点边界对 PhysX 最大 | 已烘焙 SDF 在 PhysX 命中点的绝对值最大 |
| --- | ---: | ---: | ---: |
| 左 | 0.052 / 0.061 µm | 0.061 µm | 0.060 µm |
| 右 | 0.047 / 19.513 µm | 44.505 µm | 19.514 µm |

右掌第 59 面区分了两个候选：原扇面与原生射线距离相差 9.573 µm，顶点凸边界相差 44.505 µm。仍保留原扇面，不使用凸包填补凹面。当前结果只覆盖射线路径和对应的已烘焙网格采样。PhysX 全表面等价、五指与掌面共同负载、离支撑与 Lift/Hold 均待验证。

启动入口 `python -m scripts.audit_dh116_power_palm_raycast --capture <sealed-power-capture> --output <new-directory> --execute-native`。外层记录各轮独立退出、原始射线和来源哈希。两轮共 4 个 PhysX 步、零控制与求解器步、零 PPO。111 项 CPU 回归通过。
