# 按批准在 GPU 0 共享运行独立预览

用户已明确批准共享 GPU 0。原独立预览入口固定 GPU3；本包仅为预览添加物理 GPU 选择、冻结身份与 CUDA logical0 的 PCI 映射校验，原 Teacher lease 路径仍保持原 GPU3 限制。GPU选择不能改变既定 2+128 SDK 步、1536 solver 子步、162次显式render和零PPO预算。

CPU：新增设备错配、PCI映射和冻结字段测试；设备/合同/物理预览/presentation四组共22项通过。未在CPU阶段启动Isaac；该测试不代表相机、柔性物理或自然退出通过。原生执行使用独立目录，失败不重复运行；180秒仍为协作式软截止。

当前其他训练进程的Linux账号为liuyuxuan，GPU0剩余约10.5GiB；这些进程保持不变。正式原生记录与退出状态在单次执行完成后独立报告。
