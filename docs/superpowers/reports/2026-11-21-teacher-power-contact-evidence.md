# Power same-clock pad and palm contact evidence

The Power worker now captures the actual solver buffer metadata at the same boundary as forces, nodes and named contact pairs. The 13-slot Power layout is explicit. Slots 11 and 12 bind the left and right palm, and slot 5 binds the table. The earlier supported task keeps its existing support-slot interpretation.

The opt-in `--measure-contact-evidence` path first writes the raw exchange, then reconciles pair forces and moments against the solver aggregates. It rejects swapped layouts, incomplete buffer metadata, overflow, unmatched physics/rod ticks and invalid palm source hashes. It reports individual and summed loads for five distal pads and the palm in each hand, plus the existing pad opposition and the palm-to-pad direction. The report separates table loads from either hand. The diagnostic carries no native grasp or Teacher qualification.

On GPU 2, one original grounded rod and both mounted hands produced eight same-clock records from SDK 3 through 10. All eight captures had 492 pairs in a 6,396-pair buffer with no overflow. All 3,936 pairs were table contacts, with 0.241–0.355 N normal load over the 96 solver substeps. Both hands had zero measured pad and palm loads. The maximum solver pair-force residual was 1.456 µN. App.close returned and the process naturally exited with code 0. No control or PPO update ran. Hash verification and an independent table force summation agreed with the stored evidence.

A separate offline screen used original collider meshes and a rod at the candidate support height of 0.365 m. It found geometric palm-to-pad radial cosines of −0.993 left and −0.992 right. The most distant target pad was the little finger of each hand, with gaps of 0.898 mm and 0.836 mm. The estimated minima for non-target clearance were 0.092 and 0.078 mm. These are geometric candidates. The supported Power configuration still needs both static supports appended after the two palms and a live closing trajectory that maintains the force gates. No grasp or lift has qualified.

The 364-test CPU regression covers the legacy 11-slot layout, the raw producer, separate palm identity, missing palm contribution, nonopposed palm contact and supported table load.
