# Power 双小指近端接入后的原生靠近动作

17 槽柔性场景完整复现 SDK 240 静置状态后执行一次原 24D 动作。248 个 SDK 步中包括 2 个初始化步、238 个静置步和 8 个控制物理步。DeformX 实际推进 2952 子步。8 个动作物理步逐条检查了前一帧的反力路由、7 个原名关节刚体槽、动作回读和原保护。

两个手腕仅沿世界负 X 请求 83.33 µm，实际位移左 43.23 µm、右 43.26 µm。位移由同钟 PhysX 关节读回按各自原安装基座旋转回世界坐标。左右安装轴不同，直接对比 `wrist_x` 局部关节符号会得到错误结论。实际主动手指目标保持，过程中未检测到手或桌面 pair。两端支架在动作期各有 96 个有效 solver 子步载荷，杆节点最大位移 0.212 mm。此位移发生于支架承托阶段。

原生外层与 GDB 内层均自然退出 0，耗时 63.01 秒。零训练更新。配置、冻结执行、动作日志及 App.close 记录 SHA 见 readiness，完整原始日志独立保存。下一步需要逐姿态、逐刚体的安全移动范围与首接触证据，才能测试五指与掌面的全握受力。

本次原生报告发布前的动作、接触和调度回归 85 项通过。
