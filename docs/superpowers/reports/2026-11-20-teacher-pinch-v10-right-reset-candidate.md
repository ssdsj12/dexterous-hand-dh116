# Pinch 右手净空候选

v10 原生账本和现有投影代码说明，腕部纵向平移保护只读取本步净空。腕旋转与关节运动能共同降低拇指近节的净空。此次在独立的右手 Reset 中修正起始几何，保留原控制器、原关节和 2.100 mm 桌面保护线。

对现有右手起点追加世界 Z +175 µm、世界 X −50 µm、绕世界 Y −1 mrad 和 `finger12` 种子 +0.5 mrad。左手、线缆及其承托、原物理场景沿用原配方。17 组离线筛选中两组同时通过严谨端点、连续路径和两份历史账本回放。选择回放净空余量较大的候选。固定的二指端点绝对间隙最大值为 0.03995 mm，小于原 0.05 mm 门槛。静态连续净空为 2.35270 mm。

脚本绑定两个已封存 journal SHA、公共 Reset、真实同钟腕根、17 个原始碰撞凸包来源、5 处 cooked 指腹和 11 个实际手指关节。两类回放分别应用测量关节差值和 SDK 目标差值。基线 v10 回放复现右拇指保护线穿越。原始账本仍存于 Ubuntu，报告只发布归因和 SHA。

17 项 CPU 回归通过。脚本真实运行生成右手候选 SHA `48d007fcdffa16cdc0fd3a1c711a708067de0d5cd584c8e670afe83d04927cfb`，复放审计 SHA `fc306c46901cb6840fea6c6475248ef2e456e98d820977f9cad83edbb00c4080`。选取候选时使用了这两条历史轨迹，后续新轨迹的跟踪和反力仍需实测。当前资格限于新候选 CPU 静态几何和历史反事实。下一项为单实例仅 Reset 的原生校验，无控制、求解器或 PPO 步。
