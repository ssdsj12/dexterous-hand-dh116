# Pinch 同子步四指接触及载荷证据

采用本轮已原生验证的 SDK154 双腕对齐为前缀。目标闭合量来自同一次原生姿态的四个 SDF 指垫各 −0.04 mm 条件估计。现场重复核对两手实测读回、杆节点和发出动作，分别重新认证 22 个凸包，最小余量约左 2.387 µm、右 3.395 µm。

`run_dh116_pinch_bilateral_closure.py` 用原 24D 合同同窗平滑推进四个目标关节，四个闭合窗加两个零动作跟踪窗。仅自通过 SDK154 现场门之后允许四个指定指垫接触并继续记录原始接触对。原桌面 2.100 mm、全非目标连杆和双手分离、关节、mimic、腕追踪以及力保护继续逐 SDK 步生效。未施加抬升动作，桌面仍支撑杆。

| 目标指垫 | 首个有效 solver pair | 逐指载荷峰值 |
| --- | --- | ---: |
| 右拇指 | SDK196:3 | 0.07953 N |
| 左拇指 | SDK200:11 | 0.07491 N |
| 左食指 | SDK201:2 | 0.09535 N |
| 右食指 | SDK202:0 | 0.06527 N |

SDK202 全部 12 个求解器子步都有双手同时有符号对向。最后 6 个子步四指同时大于 0.05 N。左、右手各自的两指总载荷峰值为 0.16871、0.14441 N，均小于原 0.3 N 门槛。合格双手受载对向计数为 0，尚无固定腕稳定持握或脱离支撑的验收。接触阶段的最低桌面净空为 2.170 mm，记录手杆 pair 140 条、桌面 pair 23,462 条。

完成 2 个初始化步、200 个测量步、2400 个求解子步、25 个完整控制窗，外层 184.6 秒自然退出 0。220 项 CPU 回归通过。冻结配方指纹 `cf28c51ab890b3528a6df5c4e42666f010e05d09f87306a922880312c82e2962`。外层回执 SHA `1b7ee7c43de04f74dd5d6c92460c9ceec731f62c1a859641f3f92f206441c4a5`，物理账本 SHA `ddf53e94dfa6cc95c34c107deee0b3f54161b1022a53524ff7a8cd2b57ff3382`。复现入口 `python -m scripts.run_dh116_pinch_bilateral_closure`。
