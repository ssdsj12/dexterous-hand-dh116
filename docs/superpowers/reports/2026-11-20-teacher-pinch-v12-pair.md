# Pinch v12 双手 Reset 候选

新初态让左掌相对 v11 上升 0.125 mm、X 增加 0.030 mm，世界旋转向量为 `[-0.0012, -0.0004, 0]` rad，左 thumb finger12 起始角增加 0.00175 rad。右手、同一自由杆、桌面、重力和原动作合同保持原输入。对 v9、v10、v11 的 48、19、72 个实测子步，分别核验每个账本 SHA、该回合的 Reset、两侧实际腕根、实际 11 轴 q 及同期 SDK 目标。双侧复放最低值分别为左 2.313649 mm、右 2.171756 mm。左闭合端点误差最大 0.044739 mm，连续源/烹制碰撞包络最低 2.327456 mm，拇指近节对杆的保守下界 0.044937 mm。

该候选保留原 2.100 mm 保护线与额外储备，离线使用原端点与连续路径校验。复放只是姿态与关节的几何外推，接触反力、闭环跟踪、稳定夹持和 Lift 须由 Isaac 原生验证。左右接触外力会由同一根杆相互影响。

77 项 CPU 回归通过。候选和三账本复算在独立数据目录。候选 SHA `0e49af8b5bb205c12c1ee89883ed70e42649166c7a2188c7eac463533153457c`，复算 SHA `0fb7e74b4bacb68582a35aba2ff3b7b737ff51e773044e7c99d65ba3ccc84bef`。本发布只封存 CPU 结果。原生下一步为一次 GPU 2、单实例、1 环境、2 初始化 SDK 步、1 次 Reset、0 控制/求解器/PPO，候选单独取自然退出回执。
