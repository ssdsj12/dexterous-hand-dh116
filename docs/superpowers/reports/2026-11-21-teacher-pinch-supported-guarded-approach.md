# Pinch 自由杆支架上的双侧靠近准备

用 Pinch 自己的 SDK 240 原生读回重建两手实际掌与指垫的姿态。每侧采用不同的指节和腕部增量，重新贴近原材料节点。左手搜索选用能改善拇指和食指法向夹角的候选。右手原候选全手最小杆间隙 0.247 mm，低于原保护条件，已经舍弃。

| 17 点路线，逐侧 22 个源／Cooked 形状 | 左手 | 右手 |
| --- | ---: | ---: |
| 最小保守杆间隙（mm） | 1.137 | 0.491 |
| 最小手至支架间隙（mm） | 20.506 | 2.463 |
| 末端拇指、食指 SDF 间隙（mm） | 2.358 / 1.556 | 1.605 / 0.894 |
| 末端双指几何法向点积 | −0.370 | −0.914 |

原生只在实测重新吻合 SDK 240 的关节、目标、手连杆、杆节点和反力后发出动作。动作阶段仍检查全手与杆的 0.25 mm 保守间隙、真实支架和桌面；逐物理步确认两端承托和没有非预期接触。该工作包验证靠近、坐标与指节运动，后续需要验证有力接触、持握与 Lift。

98 项 CPU 回归通过。预算为 432 SDK 步、24 控制窗、5160 求解器步、240 秒软上限、零 PPO。入口 `python -B -m scripts.verify_dh116_pinch_supported_reset --approach-reference PRIOR --approach-screen PROOF …`。
