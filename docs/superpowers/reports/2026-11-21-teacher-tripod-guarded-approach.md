# Tripod 有守卫的四窗靠近

在已原生验证的双手支撑场景上增加独立且有界的靠近序列。先复现真实 SDK 240 初态并对照整套关节和杆状态，然后只在原 24D 中下发手腕平移。左手沿世界 Z 向下至多 0.50 mm，右手沿第一段的平移方向向 +XYZ 移动至多约 0.469 mm，手指和旋转保持。原 480 Hz 及 60 Hz 控制率保持。

冻结前检查两侧目标行程与封存的杆、支架和桌面净空。原生动作阶段在原物理边界使用实际手部和最近的真实杆位置，检查 0.25 mm 的保守杆间隙与原桌面及支架保护，记录每物理步的动作和反力。出现任何手、桌面接触或失去任一支架承托时停止该诊断。该近距离步骤只覆盖到接触之前。

入口 `python -B -m scripts.verify_dh116_tripod_supported_reset --approach-reference RECEIPT …`。计划 272 SDK 步（2+238+32）、4 控制窗、3240 求解器子步、零训练、180 秒软上限。111 项 CPU 回归通过。下一步使用独立输出目录验证完整真实动作和守卫，再进入三指接触。
