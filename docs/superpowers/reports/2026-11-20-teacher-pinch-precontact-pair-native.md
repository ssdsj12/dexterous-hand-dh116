# Pinch 接触前左手暂停与右腕回调的同实例验证

`run_dh116_pinch_precontact_pair.py` 保存历史控制窗 0–1；SDK18 现场复算左手撤回动作并验证 22 个凸包，左侧随后保持。右侧保留历史命令至 SDK50。SDK50 用同实例的杆与右手读回核验右腕回调，检查右侧 22 个凸包。该边界的历史配准比较只针对右手和杆；左手此前已接受独立放行并持续监测。每个实际物理步检查完整 solver pair，若出现手杆接触立即结算为诊断失败。桌面承托保留。

| SDK18 左手预接触暂停 | 22 个凸包通过，最低条件余量 71.0 µm |
| SDK50 右腕回调 | 22 个凸包通过，最低条件余量 0.390 µm |

| 退出 | 81.4 秒，外层自然退出 0，无强制退出 |
