# Pinch 支架自由杆右手二指首次接触准备

复用已原生验证的同钟反力观测，但新配方只接受 Pinch 的右拇指、食指以及各自的材料节点。SDK 432 双手 q、qd、目标、连杆和杆状态精确重放后才开启低速 24 控制窗与 4 个零增量窗。中指仍按非目标形状和碰撞对处理。左手保持实测位置附近，独立研究其尚未对向的原因。

17 个采样位姿中，右手非目标包络至杆至少 0.350 mm、手至支架至少 0.793 mm，目标指垫 SDF 末端为 −0.057 / −0.070 mm，方向点积 −0.801。左手全手保守间隙至少 2.428 mm。原关节、手到支架、桌面保护不变。接触是否发生、是否沿正确方向以及下一步物理反力均须原生确认。

154 项 CPU 回归通过，覆盖 Pinch 不能接受第三指、材料位置和下一步反力。原生预算 656 SDK 步、52 控制窗、7848 求解器子步、360 秒软上限，零 PPO。入口 `python -B -m scripts.verify_dh116_pinch_supported_reset --distal-reference PRIOR --distal-screen PROOF …`。
