# Pinch 左腕修正原生同步对向对照

Ubuntu `1f9a1f7`、GPU 2、单实例、单环境。SDK34 和 SDK58 的同钟节点、腕位和关节读回分别与冻结参考一致。随后按原速率两窗执行左腕微调，保留双侧指动作及右腕动作。74 SDK 步、72 个有效 480 Hz 采样、864 求解器子步完整，无保护终止，进程自然退出 0（84.35 秒）。

| 独立重读的原生指标 | 左指提前基线 | 左腕微调 |
| --- | ---: | ---: |
| 左手有符号对向受力子步 | 24 | 33 |
| 右手有符号对向受力子步 | 15 | 15 |
| 双手同子步有符号对向受力 | 0 | 14 |
| 左拇指/食指峰值法向反力 (N) | 0.841/1.396 | 0.648/0.686 |

首次得到连续 14 个有效双手对向子步，从 SDK73 子步 9 到 SDK74 子步 10，约 2.43 ms。对照首个同步子步，左侧材料节点仍是 35/34，总反力余弦从 +0.181 降至 −0.986，要求的两侧投影皆为正。SDK74 最后一子步左侧总反力余弦回到 +0.0258，左拇指及食指分别维持 0.510/0.630 N 法向力，稳定资格仍欠缺。两手实测最小非目标间隙下界为 0.0271/0.0343 mm。

原生账本独立复算每个子步的接触对、四指反力和有符号对向，重新核验原始前缀、动作表和自然退出。冻结 SHA `1f8d9e4aad944939fe01adab9f3622371a7c567c0d77a2e0d5ae187cc8c2bd30`，产物 SHA 见 readiness。零保持、离架抬升、Teacher 查询或 PPO 更新。下一步以实测受力边界为参考识别仍未消化的指/腕目标并验证限速保持，再测试离架抬升。

独立 Tripod CPU 支线在右手弯杆终点搜索加入小幅腕转。限制项 `source:finger13_link` 的下界由 0.0121 mm 增至 0.0308 mm，仍小于该指链无接触跟踪形状偏差 0.0535 mm，拇指终点名义上界变为 0.507 mm。这个候选未提交原生运行。Power 本轮无新原生运行。
