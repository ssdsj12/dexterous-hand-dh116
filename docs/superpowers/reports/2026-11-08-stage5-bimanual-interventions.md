## 首回合隔离与已知执行缺陷

该冻结 Z3 版本在部分环境首终止后，GT 协同投影会在后续物理 reset 的回合中重新合成请求。当前报告在每个环境的首次 terminal 物理样本处截断，只使用该环境第一回合的 live 数据，后续 no-op 或新回合数据均排除。审计通过的是来源 action tape 的首终止后零尾部以及第一回合统计完整性，无法据此认定实际投影后执行的零尾部通过。

后续源代码增加 closed/next-episode admission mask，并用 CPU 回归验证，当前原生四组均使用各自冻结源码完成，未为修复该缺陷重跑。因此本报告中的 66/100 三指关节越限和全部 0 成功结果均保留为本次真实结果。未来源代码的 CPU 修复不改变这些历史物理证据。
