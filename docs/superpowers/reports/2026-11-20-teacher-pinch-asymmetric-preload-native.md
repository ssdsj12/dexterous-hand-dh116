# Pinch 非对称预载与固定腕反作用力

SDK282 归档的左手双指追加闭合在近端食指连杆 `finger22_link` 失去条件净空证明。使用相同实测锚点，左手仅增加拇指目标 0.750 mrad，保留食指目标。右拇指和食指分别增加 0.997 / 0.481 mrad。现场重新核对前缀、双侧反作用力、冻结动作和逐侧净空后，执行两次追加策略窗和八次固定腕观察窗。左食指命令和 12 个腕部动作通道的追加量都严格为零。

| 指标 | 实测 |
| --- | ---: |
| 追加阶段四指同时各超过 0.05 N | 960 / 960 子步 |
| 双侧同子步达到原载荷和方向门槛 | 473 / 960 子步 |
| 零增量观察阶段的双侧达标 | 420 / 768 子步 |
| 连续双侧达标最长 | 16 个求解器子步 |
| 达标覆盖全部 12 子步的物理帧 | SDK316、SDK360 |
| 最后一控制窗左手合力 min / median / max | 0.227 / 0.297 / 0.352 N |
| 最后一控制窗右手合力 min / median / max | 0.301 / 0.358 / 0.378 N |

左右反作用方向在本阶段 960 个子步均保持对向。末窗主要差值来自左手合力反复穿过 0.30 N。追加阶段仍有 36,585 个桌面接触条目，未执行离桌、净 Lift 或 Hold。后续需结合既有近端指段和桌面净空，先验证固定双腕下的连续实测载荷资格，再推进离架动作验证。当前结果为接触与预载测量，抓取成功及 Teacher 准入待验证。

Ubuntu 原生入口为 `python -m scripts.run_dh116_pinch_asymmetric_preload`。冻结计划：45 控制窗、362 SDK 步、4,320 求解器子步、单环境、GPU 2、零 Teacher 查询、零 PPO。外层自然退出 0（311.58 s）。225 项 CPU 回归通过。物理账本、每窗摘要与冻结 SHA 均记录于 readiness。
