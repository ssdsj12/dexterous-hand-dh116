# DH116 双目分割与线缆对应复放

真实保存帧复现了分割后重建断层。前视二指/三指的 visible head IoU 为 0.585/0.699，加入实际运行的 unknown 屏蔽后降至 0.111/0.113。Roll20 由 0.625/0.740 降至 0.155/0.158。前一组数字使用训练诊断的 visible logit 阈值，后一组使用真正传给旧 matcher 的布尔 mask。两者在同一原始帧、同一 native 左 ID 支持上计算。旧 matcher 又要求左右预测 mask 在候选中心及窗口重叠，限制了 RGB 证据。硬 mask 的重放保留了前视 0/0、Roll20 0/1 个采样点的结果。

`SoftWireCorrespondence.compute` 将既有 RGB 线缆候选与左预测候选取并集。搜索使用完整的 RGB 灰度窗口及原配置的 8–192 px 视差边界。分割概率只给窗口 ZNCC 代价增加最多 0.03，右预测不剔除窗口或候选。反向在正向查询的实际右图像素独立搜索全范围并验证 LR。接受点须经过纹理、匹配质量、唯一性、边界、LR 与深度范围检查。局部亚像素步长 1/8 px，细化需要改善 RGB 代价。输出保留 NaN 和无效点，由既有可见片段提取器采样实测点。既有原始 RGB processing 合同、匹配实现和默认相机原样保留。

`audit_dh116_wire_correspondence.py` 独立运行四种方法。每帧归档左右原始 RGB、原生 ID 及预测 mask、可见概率、原始及通过检查的视差、LR 一致性、有效深度、采样后 3D mask、状态及拒绝码。参考数据只在匹配完成后评分，输出绑定原始捕获、参考、相机、分割 Checkpoint 和固定位置的 SHA。右 native ID 在两组历史捕获均缺失，右 IoU 和真对应准确率/覆盖率均未记录。右光轴 Z 提供几何检查，未被当成线缆 ID。左右真实对应仅在 native 右身份与 optical-Z 验证通过的位置定义，预测对应还须在 ±0.5 px 内且投到右侧实际线缆区域。未解析、缺失、出画均标记 unknown，不作为遮挡真值。
