## 重建结果的含义

下表是既有 Roll20 RGB 的同 cohort 离线复放；两种抓法均每帧 96 个来自不同实测像素的表面点，不是96个正确点。每个初态的4帧结果相同，不是4个独立初态。

|抓法|正确点/有效点|固定原生参考分母|正确三维完整率|欧氏 MAE / RMSE / P95 / P99，mm|
|---|---:|---:|---:|---|
|二指|91/96|2009|4.5296%|2.748 / 5.015 / 6.176 / 21.981|
|三指|89/96|2054|4.3330%|3.345 / 5.977 / 20.710 / 22.138|

正确标准保持同像素欧氏三维误差≤5mm，分母没有随采样配额改变。32配额的31/30正确点对应1.5431%/1.4606%。增加配额改善已测数据的采样覆盖，未改善 dense matcher 本身或误差尾部。Ribbon表面点和图像中心线分别编码，两者均不作为 Cosserat 材料节点。Roll20、surface96和分割模型均为显式实验配置，不替换默认。

用户追加预检后，对768个输出逐点回溯到实际像素、深度、可见路径及ribbon约束；48条超过5mm的记录实际是12个env/pixel位置在4帧重复，独立物理初态仍只有2个。历史采样产物没有保存component_id/track_id，因此只能证明像素可归属于可靠可见片段，不能声称验证了历史存储的片段或轨迹ID。右侧原生实例标签缺失时，图像窗口证据只能作为诊断，不能将颜色或重投影代理当作确定的手指遮挡身份。

12个尾部位置的预测视差为42或44像素，参考约43.118–43.216像素；右侧参考光轴深度未显示相应遮挡代理。实际复放选择的是整数`wire_silhouette`且显式`subpixel=False`；原始采集的blockmatch配置为true，不能把不同算法的配置混为同一执行路径。该观察提示量化及错误匹配问题，不等于已证明唯一原因或完成亚像素算法修复。

真实 native 左实例监督下分割拟合可降低训练误差，但实际预测 mask 接入 stereo 的首帧实验仍失败，不能用分割 IoU 替代三维验收。原80次优化的失败模型和两个200次优化模型均独立保留；未用标签替换预测 mask。详见 [WP1报告](2026-11-11-stereo-wp1-native-label-segmentation.md)。
