# Power 撤离和开指完整原生复验

本次使用不可变的已发布工作树，进程正常关闭并自然退出 0。首次尝试的物理运动与本次记录逐元素一致。先撤离再开指的联锁在 SDK 496 验证双手各实测退 3.925 mm，总位移各约 4.000 mm。主要开指关节实测约 −0.195 rad，右 finger12 受原有关节下界约束，实测 −0.119 rad。

80 控制窗共 640 物理控制行，两端支架各有 7680 个接触子步，桌面与手没有与杆接触。总计 880 SDK 步、10536 求解器子步、零 PPO。GDB 内外退出 0，耗时 192.94 秒。相关联合 CPU 回归 154 项通过。原失败保留独立回执，未覆盖。

接下来从实测开手状态筛查侧向包覆路线。该原生结果覆盖撤离、开指及关闭，尚需测量掌面和五指包覆力、稳定持握与离架抬升。
