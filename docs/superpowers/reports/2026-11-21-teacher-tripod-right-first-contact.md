# Tripod 右手三指首次接触诊断准备

从已实测的 SDK 528 路点开始，同一原生实例按原命令完整重放。先比对杆节点、关节、连杆位姿与上次封存结果，再做 24 个低速右手接近控制窗和 4 个零增量窗。待接触的形状绑定真实右手的拇指、食指和中指及各自的材料节点范围。全手与支架、桌面和原关节保护依旧执行。仅接触阶段的三个目标形状采用各自同钟 SDF 深度保护，其余形状仍须有至少原 0.25 mm 杆间隙。

17 个采样位姿在原真实杆路径上测得，右手非目标包络至杆至少 0.996 mm，手至支架至少 0.541 mm，三个右指垫的末端 SDF 目标均约 −0.070 mm。左手沿用自己的实测目标附近状态，保持约 0.742 mm 全手保守间隙。几何筛查仅用来编译动作，首次接触和荷载由活求解器记录。

Antigravity 核查了 SDK、完整 17 槽和失败记录。Codex 单独核对到第 k 步生成的 DeformX 反力只会在第 k+1 步下发至 PhysX。新的观察器逐 tick 写入原始行，允许目标指接触后继续并验证下一步的力、力矩、body ID 与坐标归属。非目标网格／材料节点仍立即留下原始行再停止。支架卸载逐步记录，当前没有离架和抓取晋级证据。

151 项 CPU 回归通过。GPU2 单实例预算 752 SDK 步、64 控制窗、9000 求解器子步、420 秒软上限、零 PPO。运行入口 `python -B -m scripts.verify_dh116_tripod_supported_reset --distal-reference PRIOR --distal-screen PROOF …`。
