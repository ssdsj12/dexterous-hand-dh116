# Independent CPU wire-feedback Teacher

The candidate owns a private copy of the current context Teacher. It adds independently optimized actor and critic branches for per-palm wire position, tangent, and the previous control interval's measured pad and palm load. It retains the old common state, rod features, task context, action shape and Tanh Gaussian PPO. The actor residual is zero-initialized and limited to ±0.25 in the pre-Tanh latent space. It does not change action bounds, controller behavior or success criteria. A missing-feedback observation still returns the current base output exactly after the residual learns.

The candidate consumes explicit geometry and load masks. The original trace's unavailable entries are checked before conversion to NaN in the model-facing tensor tree. The network masks unavailable entries before numerical processing and includes the validity bits. Measured zero force and unavailable force are distinct. Fixed metre and newton scales require no specimen identity, weight, diameter, stiffness, or privileged material station ID.

The replay packer validates the independent original observation SHA-256, the exact pre-action clock and SHA-256, the feedback digest and the preceding interval indices. CPU tests reject altered inputs and bind the candidate to a new observation schema, weight identity and grasp-specific namespace. The established C05 checkpoint and native collector retain their original admission rules. These tests cover separate weight state save/load. Candidate optimizer resume still needs its own contract.
