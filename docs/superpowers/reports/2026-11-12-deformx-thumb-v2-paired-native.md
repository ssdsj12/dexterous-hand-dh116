# DH116 左右拇指 v2 原生接触标定

同批次 `eb31c79-thumb-once` 在 Ubuntu GPU 3 以单 Isaac 实例依次运行左右各一次。左侧在冻结提交 `0764fb95e1a2cb99c3a851385d0cd26c75139ffe` 执行。右侧在左回执进入本地发布队列后启动，运行提交为左结果提交 `81f3c543912c50dcb248382472c652430131d64f`。右侧仍使用原批准的配置和源码指纹。两侧的原生接触记录和自然退出有效。本批物理预算不合规，不能授予完整原生资格。

## 物理预算偏差

批准范围为每侧最多 240 个物理步，双侧合计 480 步。SDK 在接触账本启动前的 `SimulationContext.reset()` 初始化路径中已执行两个 PhysX 步。安装 SDK 的 reset 实现会渲染两次，playing timeline 下每次渲染触发一个实际物理步。账本首条对应 SDK tick 3，物理时间为 3/480 s。最后一条对应 tick 242，物理时间为 242/480 s。每侧为 2 个初始化步加 240 个记录步，实际总数 242。双侧合计 484 步，比批准预算多 4 步。

原调度器按 `physics.jsonl` 的 240 条记录判定每侧预算，因此历史回执的 `native_qualification=true` 只反映当时的账本计数规则。保留两侧原始回执和账本，撤回本批完整资格结论。原生接触和自然退出证据仍可用于技术分析。本报告没有重跑任何实验。

## 资格范围

两个独立实验仅覆盖单拇指与零重力、双端固定杆的接触、反作用力交换和进程释放。单手多指对向承托、双手作用同一根自由杆、真实重力及无外部支撑的 Lift/Hold 仍需独立原生验证。30 mm Lift、5 s Hold、0.5 mm Slip 标准原样适用。此次 Teacher、Student、BC、DAgger、PPO 更新和抓取成功计数均无资格结果。
