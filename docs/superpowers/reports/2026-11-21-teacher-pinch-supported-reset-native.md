# Pinch 支架自由杆 Reset 原生复验

独立单实例带实际 DeformX 反力执行。原生读回确认两端受支架承托，手和桌面没有杆接触。杆节点位置和速度与同一支架几何的无手接触参考逐元素一致。

| 实际测量 | 结果 |
| --- | ---: |
| SDK 总步数（含 2 初始化步） | 240 |
| 测量行 / 求解器子步 | 238 / 2856 |
| 两端支架有效接触子步 | 各 2856 |
| 两端支架峰值合力（N） | 0.15646 / 0.15651 |
| 左右手最小桌面净空（mm） | 64.0284 / 59.6754 |
| 初态手至支架最小间隙（mm） | 6.8016 |
| 手和桌面接触数 / PPO 更新 | 0 / 0 |

确认无固定杆节点或外加杆力。所有归档物理行和结果均按外层回执核对 SHA，SDK 3 是静止初始交换，SDK 4 起每行反力绑定上一物理 tick。GDB 内外自然退出 0，墙钟约 61.95 秒。相关 94 项 CPU 回归通过。

可从该原生末态继续筛查独立双手靠近路线。接触资格、固定腕持握、离架 Lift 和 Teacher 准入当前仍缺证据。入口 `python -B -m scripts.verify_dh116_pinch_supported_reset`。
