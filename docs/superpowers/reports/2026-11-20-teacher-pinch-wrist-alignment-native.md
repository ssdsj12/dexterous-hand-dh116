# Pinch 双腕调整及闭合净空筛选

针对 SDK106 固定腕闭合中左食指近端间隙不足、右拇指近端证书未决，比较单轴与组合腕位移。实测锚点的离线反例显示，单纯降低左腕 0.45–0.60 mm 并附加负 pitch 会让左拇指近端越过原 2.100 mm 桌面保护。证书现用实测连杆刚体校正后各独立平移轴的 z 投影估计桌面高度变化，杆净空仍用原三维欧氏位移界。根目标按原 24D 平移／旋转速率球提交，保持指目标、原形状和逐 SDK 步保护。

修正版在 SDK106 核对当次初态、重编动作及双侧各 22 个凸包，再下发左右腕调整。保留了接触前全杆漂移和实测手杆 pair 的保护，现场最小条件裕量左 7.334 µm、右 4.753 µm。

共 2 个初始化步、152 个测量步、1824 个求解子步、19 个完整控制窗，外层在 148.9 秒自然退出 0。杆节点最大位移 7.45 nm，桌面 pair 74,784 条、手杆 pair 0 条。腕角目标与实测存在残差，后继闭合必须使用当次读回。

从本轮同实例 SDK154 重新计算指令目标和两手独立跟踪盒。四个目标指垫深度 −0.04 mm 的候选已通过 CPU 条件检查，最低余量左 2.387 µm、右 3.395 µm。更深的 −0.08 和 −0.12 mm 左拇指近端仍未证实，右侧则通过。指垫深度为 SDF 估计。后续实验只放行目标四指接触，保留非目标、桌面、inter-hand、独立腕追踪、关节及力保护，并用原 solver pair 判定同子步双侧对向。尚未取得固定腕保持、抬升或 PPO 资格。
