# 默认工作包切换至柔性线缆

用户确认 DeformX 柔性计划。默认调度目标由 `wp6.rigid-native-final` 切换到 `flex.f10-actor-only`。目标的实际依赖覆盖 F0–F10、F4 碰撞几何预检和 F5 数据接入。F4 原生步骤同时依赖 F3 双向耦合与原指腹几何预检。原刚性终点继续登记，可用 `--plan --scope all` 检视。

新增回归以实际仓库 registry 调用调度器，首先复现默认仍指向刚性旧目标，再验证新的依赖闭包。Ubuntu 调度器测试记录保存在工作包日志。既有发布机制、保护源码和原生成功标准沿用。调度目标选择只改变默认依赖范围，原生实验和正式训练继续依据各自的证据及批准预算运行。
