# Power 换工位与固定掌面轴心对照

Antigravity 复读相同源码 SHA 后确认旧候选闭合的杆初筛将保守下界低于零的候选全部拒绝。新增模式仅对上下界跨零的凸包用原 `endpoint_gap` 复查，复查下界仍小于零就拒绝。保留原桌面、杆和支架限制，保留原六主动关节范围。

左侧沿既有 41 节点杆的局部正交坐标，将开手掌位从工位 33 平移并运输到工位 32、31、29。右侧从 0.140 mm 掌面见证点出发，分别绕杆切向和 `tangent × inward` 旋转 ±5°、±10°。当前直杆上，两轴分别为世界 +Y 和 +Z。刚体 FK 确认平移和旋转共同保留该世界掌面点。每一候选用实际原几何检查桌面、支架、杆和拇指净空。只在张手终点通过后重解闭合。

| 对照 | 结果 |
| --- | --- |
| 左原工位 33 / 32 | 均与支架形状交叠 |
| 左工位 31 / 29 | 支架净空下界 5.460 / 30.460 mm，掌面间隙上界均为 0.188 mm，中指间隙上界仍为 24.000 mm |
| 右绕杆切向 −5° / −10° | 掌面上界 0.121 / 0.062 mm，可进入关节搜索。−10° 的中指上界由原 35.833 mm 降至 35.329 mm |
| 右绕杆切向 +5° / +10° | 桌面净空拒绝 |
| 右绕世界 +Z ±5° / ±10° | 掌面与杆的几何距离上界为负，全部拒绝 |

各通过张手净空候选的左右 Y 分离下界最小为 165.576 mm。没有一个闭合结果满足五指和掌面同时靠近。两侧中指都成为瓶颈，下一步需要在保持当前掌面见证点的同时约束中指和拇指的闭合路径，并补齐 locked cooked 掌面和接触载荷来源。
