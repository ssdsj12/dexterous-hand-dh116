# Pinch v10 原生结果与右拇指净空归因

v10 只运行一次。SDK 初始化 2 步，之后记录 19 个连续物理步和 228 个求解器子步。前两段各 8 步。第三段记录 3 步后在 SDK 第 21 步触发 `post_step_source_clearance:right`。原 2.100 mm 保护线下的实测净空为 2.098153 mm。终止部件为 `right:source:finger13_link`。GAE 记录物理终止，终点 bootstrap 和递推均关闭。PPO 更新为 0，无 checkpoint。

使用已保留的实际关节和凸包读回复算右拇指。初始 FK 净空为 2.243063 mm。相对初始的下沉分解为腕根位置及旋转合计 −102.213 µm，主动关节 −42.662 µm，被动联动余量 −0.002 µm，复算与实测残差 −0.035 µm。以当步 SDK 目标代入同一腕根的理想跟踪分量为 −68.148 µm，该值仅用于归因。实测 `finger12` 为 0.037819 rad，目标 0.037340 rad。该次停止由桌面几何保护触发。

第二段完整控制步墙钟约 7.144 s。v9 同序号为 13.085 s。两次冻结 Reset 相同，但实际初始权重、模型身份和采样动作均不相同，且策略输入包含真实剩余墙钟。这里提供描述性对照。吞吐改进的配对因果证据来自单控制步作用域报告中基于同一原始记录的 CPU 复放。

外层自然返回代码 1，用时 133.203 s，GDB 无终止信号。故障路径返回，生命周期门控仍未证明全部资源释放。原始 102 条账本 SHA `fa7e6300ac5a48804a00b4f9e0b30bbda010e88168bf2114cb0850d18bbdb878`，外层回执 SHA `178c53d37bf896a3d05349247a39dfd579f08e96a5ed7b1c9d73f2720e8d5f64`，离线归因文件 SHA `397132f8771c6d134e4bb924599ffc60c39eb95df96a83a6fa36c041ecbd113b`。原生原始文件留在 Ubuntu。相关冻结配方和 PPO 回归为此前的 97 项通过。

下一项需要将新诊断的初始权重与探索随机种子绑定到完整来源，并在实测腕根和指节联合运动下评估现有净空。手指姿态和反事实 FK 证据仍需与双侧反力、离架净 Lift、Hold 和 Slip 分开验收。此工作包不启动新的 Isaac 实例。
