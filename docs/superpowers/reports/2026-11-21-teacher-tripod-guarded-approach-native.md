# Tripod 双手实际靠近原生结果

本次从独立 Tripod 任务的实测 SDK 240 复现同一杆、双手关节、反力和位姿，再使用既有 24D 动作入口执行 4 个控制窗。32 个动作物理样本按一一对应的 SDK 与 DeformX 时钟核验，7 个反力体各自保留真实标签。

用实测 PhysX 腕关节和各自的安装坐标换算到 World，左手 Z 下降 0.425 mm，右手沿 World XYZ 分别移动 +0.170、+0.255、+0.255 mm。每个动作求解器子步均仅由两端支架提供法向载荷，支架各记录 384 个子步 pair。无手、桌面接触，也无净空、关节或跟踪终止。

共 272 个 SDK 步、3240 个求解器子步、零 PPO，87.28 秒，原生与外层自然退出 0。已按外层回执检查所有原始文件 SHA。111 项 CPU 回归已随配方独立发布。命令入口 `python -B -m scripts.verify_dh116_tripod_supported_reset --approach-reference RECEIPT …`。此路径证明真实靠近和反力接口可连续运行，后续需以当前实测姿态重新计算靠近余量，并单独建立三指的有效接触与抬升证据。
