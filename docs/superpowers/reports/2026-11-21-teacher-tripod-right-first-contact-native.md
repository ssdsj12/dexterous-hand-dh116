# Tripod 右手三指首次接触原生结果

右手在原 DH116 与 DeformX 自由杆上取得三指实际接触。第一笔右拇指力在 SDK 696 求得，SDK 697 向对应 PhysX 刚体写入 0.00219 N 的世界坐标反力。224 个新增原生行逐行核对同钟身份、完整接触缓冲、力矩平衡与上一行反力下发值。

| 指腹 | 首次 SDK | 原生接触对数 | 单对峰值法向力（N） |
| --- | ---: | ---: | ---: |
| 右拇指 | 696 | 673 | 0.17308 |
| 右中指 | 722 | 371 | 0.14280 |
| 右食指 | 732 | 248 | 0.08702 |

57 个 SDK 行有目标接触，56 行实际下发上一子步组生成的反力。右手有 8 行每个求解器子步都满足三指载荷和对向门槛，最长连续 2 SDK 步，约 4.17 ms。左手 0 行。两端支架在新增 2688 个子步中持续承托，峰值分别约 0.159 N、0.162 N。未观测到桌面、手掌、非目标手指或错误材料节点的接触。下一步需在保持已见右手载荷的同时取得左手接触，并在独立反馈窗验证稳定性。还未验证双手持握、30 mm Lift、5 s Hold 或 Teacher 准入。

总计 752 SDK 步、64 控制窗、9000 求解器子步、零 PPO，GDB 内外自然退出 0，204.28 秒。相关 151 项 CPU 回归通过。入口 `python -B -m scripts.verify_dh116_tripod_supported_reset --distal-reference PRIOR --distal-screen PROOF …`。
