# Power 先撤离再打开的双手动作准备

直接向旧姿态靠拢的 8 条路线所测近端法向均朝掌外。新的阶段先沿世界 X 撤离 4 mm，再按原 24D 关节合同打开。主动开指最大 0.2 rad，拇指旋转保持原设定，右 finger12 依原下界约束。以真实 SDK 240 的双方连杆、关节、杆状态及支架布局为起点。每侧每段 65 个采样，逐形状扣除相邻 FK 位置间的最大运动界。

| 认证的最小间隙（mm） | 左撤离 | 右撤离 | 左开指 | 右开指 |
| --- | ---: | ---: | ---: | ---: |
| 线缆 | 4.335 | 6.125 | 1.247 | 2.445 |
| 支架 | 10.279 | 22.462 | 1.179 | 24.470 |
| 桌面 | 7.338 | 31.801 | 7.370 | 31.832 |

活体撤离结束实测掌根位移均至少 3.5 mm 才允许开指。两段沿用全手杆、支架、桌面和关节监控。该动作用于为 Power 侧向包裹建立空间。后续路线仍需要掌面与五指反力和完整 Lift/Hold。独立左侧搜索已找到掌与部分手指方向对立的姿态，但掌仍离 2.018 mm，小指离 2.587 mm，食指方向不合格，保留候选不授予准入。

153 项 CPU 回归通过。准备预算为 880 SDK 步、80 控制窗、10536 求解器子步、420 秒软上限、零 PPO。入口 `python -B -m scripts.verify_dh116_power_retreat_then_open --retreat-reference PRIOR --retreat-screen PROOF …`。
