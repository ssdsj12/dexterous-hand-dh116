# Pinch 在连续对向窗口后恢复载荷

切向探针的原生第四段表明，左手方向有所改善，但总力不足。SDK 411–418 的 96 个求解器子步首次在其末段出现完整对向窗口。左手 87/96 个子步低于原总载荷门槛，右手 1/96。按历史原始力与当前净空证据重放已有反馈选择器，在 SDK 418 会只选左 finger21 增量 +0.00005 rad。此结果属于封存轨迹上的决策重放。

新增独立配方保留先前切向试验的首 52 窗及其独立原生身份。在当前现场必须重新满足全部原符号、载荷来源、实际关节净空与动作限制，才允许最多两个原幅度的左食指增量。若新子步不再连续对向，动作继续为零。腕和右手保持。SDK 418 时的现场状态需与已封存对照逐项比较。

112 项 CPU 回归通过，独立入口 `python -m scripts.run_dh116_pinch_tangent_force_hold --tangent-archive OUT …` 完成冻结。仍用 442 SDK 步、5280 求解器子步、55 控制窗、零 PPO、520 秒软上限。需要实际对照确定载荷是否恢复。该探针不执行抬升。
