# GPU0 单次预览失败与启动依赖修复

批准范围为共享GPU0、单实例、零PPO、2初始化+128测量SDK步、1536求解器子步和162次显式render。实际源码3e277dcdffbd3f38f219a37902f6d1b770385d69，合同c3939b7ee5a348864c4ddf970f952861c24c5b40754f8a6f16fc53a21b09a208。只启动一次，未自动重试。

**实际失败**：日志显示Streaming server started，但AppLauncher构造未返回；其_hide_stop_button在livestream>=1时导入omni.kit.widget.toolbar，当前headless.rendering experience未启用该扩展，抛ModuleNotFoundError。随后退出清理SIGSEGV，GDB顶部libomni.ext.plugin.so，经carbOnPluginShutdown/Kit退出链；动态库映射和线程栈已保留。这证明清理路径发生崩溃，不能单凭无符号栈定位底层内存根因，也不是PhysX Tensor View已建立后的故障证据。

外层实际退出255，inferior signal11，未使用SIGTERM/SIGKILL或os._exit。未创建任务scene、physical.jsonl或双RGB图像，测量行0、PPO0。App内部总SDK/渲染数没有独立仪表，不声称其全局计数为0。自然退出及柔性显示、相机同步均未通过。

**修复**：只为独立预览的冻结launcher加入kit_args="--enable omni.kit.widget.toolbar"，在App创建之前启用已安装扩展；不修改IsaacLab或IsaacSim安装、物理、动作或Teacher代码。已核对本机toolbar扩展的on_startup创建工具条实例，符合AppLauncher后置钩子；通过注入launcher测试验证冻结启动参数在该钩子之前交付。CPU设备/合同/预览/启动回归24项通过，不能代替原生复验或证明SIGSEGV已消除。

原始日志只保留服务器证据目录attempt-gpu0-e8a60161，不上传Git。日志SHA256 56361a28a9528c496980572260adad83c93bb6fd100c4c3728d55127550bf0f1；结构化摘要见docs/contracts/physical_preview_native_readiness.json。其他用户的两个训练进程仍在运行。修复发布后需重新冻结指纹并向用户申请下一次有界原生预算。
