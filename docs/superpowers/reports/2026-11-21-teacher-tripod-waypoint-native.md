新增 192 SDK 步内，两端支架各有 2304 个求解器子步记录，未观测到手或桌面与杆接触。全程 432 SDK 步、5160 求解器子步、24 控制窗、零 PPO。GDB 内层与外层自然退出 0，墙钟 146.25 s。原配方的 CPU 回归 112 项，本次发布复验 87 项通过。复核使用保留的冻结计划、外层回执和逐步原始记录。
