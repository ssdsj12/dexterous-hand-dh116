# Pinch 左食指提前闭合的同钟预检

Antigravity 核对了 `7570557` 和闭合、几何、Tripod 跟踪源码。独立重读显示，原始 SDK54 左拇指已经先受力，左食指还差 1.246 mm，随后间隙到 SDK74 减至 0.232 mm。追加左腕回调的实测对照把间隙增到 0.258 mm。根据实际位姿、主动与被动关节及杆节点的冻结替换，增量中约 +32.5 µm 来自腕角变化。当前工作包把左腕与右手指令留在原轨迹，将最小对照集中在左拇指和食指。

## 修改及实测复放

- `compile_variant()` 从 SDK34 后的五个控制窗增加左拇指和食指累计目标 +0.0026 rad 和 +0.0070 rad。原归一化动作分别 +0.104 和 +0.280，其余 22 项与前四窗保持原始数据。
- `load_reference()` 校验原始外层自然退出、冻结账本 SHA、原始反力回执与每步同钟身份。`measure_boundary()` 用原 SDF、原关节映射和实际腕位，保留被动关节原跟踪残差。对左右动作保持对照，给两个新增左指执行分量设独立 80–100% 条件盒，并对每个历史杆节点加 0.050 mm 敏感性余量。
- SDK34–74 共 41 个读回边界。盒内全非目标几何的最小保守余量为 0.0204 mm，限制处为 SDK74 源 `finger22_link`。末帧中心和四角的左拇指 SDF 为 −0.127 至 −0.158 mm，左食指为 −0.135 至 −0.224 mm，法向点积 −0.795 至 −0.768。五个样本达到原名义端点门槛。
- 相关 CPU 回归 165 项通过。首轮测试暴露夹具的桌面高度低于现有合同，夹具纠正并新增保护拒绝断言。运行命令和 SHA 见 readiness。

各盒以独立的 480 Hz 实测样本及其固定腕位为参考。已计算条件盒内部的关节位移界，末帧 SDF 为五个采样点。未观测新轨迹的腕位漂移、力或步间连续碰撞。下一步将该方案接入原生预览的前缀同钟、现有现场保护和可自然退出的有界诊断路径，再测对向反力。

Tripod 的 0.021 mm 直杆实测只覆盖原固定腕姿和无接触运动。原弯杆受载、被动耦合变化和近端余量仍需新测，继续使用独立证据链。

本包零新增原生步、零 PPO 更新，测试结果无 Teacher 晋级含义。
