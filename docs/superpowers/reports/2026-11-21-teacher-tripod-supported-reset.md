# Tripod 独立支撑初态与原生预检

加载左右各自 Tripod 接近首点，再分别核对碰撞体。保留原自由 DeformX 杆、真实重力、两端支架和双手原始 17 槽碰撞资源。候选仅在左手初始掌位增加 +2 mm 世界 Z，右手原首点保持。Tripod 生成独立任务标识、独立 Reset 回执和测量文件。

把真实初始杆和 238 个已封存的姿态按同材料段聚合，使用支持平面将各测得杆心线和半径完整包住。对各手全部 22 个原始/锁定碰撞包络验证。此下界覆盖已知形态和它们的线性组合。当前没有把它用作未来杆运动预测。

独立入口 `python -B -m scripts.verify_dh116_tripod_supported_reset` 按原 17 槽耦合方式注册、记录位姿与反力，每 SDK 帧实测手部源形状的桌面和支架净空。保留 stationary Reset 首帧保护，出现任何手部 pair 即结束静置诊断。已冻结 2 初始化步加 238 次测量、2856 求解器子步、零控制/训练、180 秒软上限。107 项 CPU 回归通过。下一步在已批准的单实例预算内执行原生验证及自然退出核对。当前阶段仍未获得 Tripod 稳定抓握证据。
