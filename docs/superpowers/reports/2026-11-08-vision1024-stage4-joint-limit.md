# M2 三指右拇指 joint_limit 根因与动作合同审计

两次历史终止均由**右手拇指第二主动关节 `finger12` 的实测角度穿过下界保护线**触发。按原 24D 动作逐步重放，在相同环境、回合、子步和时间复现了两次事件。到达终止时，传给 Isaac SDK 的两个主动关节目标均在合法范围内。单独中和手指、平移或旋转，使原事件在这段回放中均消失。现有证据支持手指驱动与腕部运动共同作用下发生物理跟踪偏差；各个接触冲量、被动耦合及驱动扭矩对偏差的贡献尚未测定。

## 终止样本

数据来自 2026-11-08 的原生 1024 环境、32 个 policy step 的历史 M2 段和同动作重放。每手共检查 17 个 articulation DOF，右 `finger12` 是这四个越限样本中唯一越过保护线的 DOF（包括后述省略逆变换组的两个样本）。该 DOF 在两手均为 SDK 索引 11。运行时实测下界为 0.007912623 rad，容差 0.020000 rad，触发线为 −0.012087377 rad；上界为 1.030000 rad。下表动作是物理指令的归一化速度，角度和目标均为 rad。

|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 1:932:0 | 32799 | 252 | 0.562500029 | −0.254340 | 0.039643 | −0.012651 | 0.000564 | 0.8833 / 2.4326 |
| 1:799:0 | 32799 | 256 | 0.570833363 | −0.267491 | 0.042211 | −0.013073 | 0.000986 | 0.2137 / 6.4151 |

历史 480 Hz 文件保存了两个 terminal、episode_uid 和实际送入任务的 24D 动作；历史 60 Hz 文件保存了原始 Actor 动作。关节位置及 SDK 目标取自复现同一终止的独立重放。每条重放行都有 `actor_raw24`、`actor_bounded24`、`physical_action24`、双手 `sdk_active_target_rad`、`active_q_rad`、全 articulation 的 `q` 和 `limits`。932 的余下 4 个 no-op 已和有效终止样本区分；799 在最后子步结束。

逐条关联了两个环境各 256 个历史物理样本及对应的 60 Hz Actor 动作。512/512 条在 policy step、物理动作 24 维、仿真时刻、存活标记、终止标记及双手接触载荷上与原动作重放完全相同。env 932 最后四个有效子步的右 finger12 角度依次为 −0.009559、−0.010710、−0.011618、−0.012651 rad，终止前已持续朝下界运动。env 799 相应角度为 −0.011243、−0.011245、−0.011578、−0.013073 rad，最后两个子步右手接触载荷由 0.0863 N 升至 6.4151 N。这是整手载荷，无法从中单独识别拇指接触力矩。

## 五组原生开环对照

所有组使用相同的 32 步 Actor 原始输出，所有 1024 个环境均参加重放。五组 reset 后的关节位置、速度、根位姿和线缆状态合并 SHA-256 为 `f41f42a5ca0f95c539a6dcc275adf2b9cbda69861bbe08119f7937dfd65975d4`。中和从第一个动作开始，置零的是该组两只手的归一化速度指令。下表两个固定子步的数字分别为右 `finger12` 实测角度与 SDK 目标（rad）。

| 回放动作 | 32 步内 joint_limit 数 | env 932 第 252 步 q / 目标 | env 799 第 256 步 q / 目标 |
|---|---:|---:|---:|
| 原始 M2，执行逆变换 | 2 | −0.012651 / 0.039643 | −0.013073 / 0.042211 |
| 手指 12 维置零 | 0 | 0.011750 / 0.031916 | 0.031894 / 0.031916 |
| 世界平移 6 维置零 | 0 | 0.003176 / 0.039643 | −0.004040 / 0.042211 |
| 局部旋转 6 维置零 | 0 | 0.009922 / 0.039643 | 0.001746 / 0.042211 |
| 省略整组动作逆变换 | 2 | 0.006648 / 0.022833 | 0.012845 / 0.016087 |

单独中和平移或旋转后，在上述子步右指 SDK 目标与参照组相同，实测角度有明显变化。省略逆变换后，原两环境均未在该时刻终止，另两组三指轨迹触发了同一 DOF 的保护：env 975 第 242 步为 −0.012680 rad（目标 0.022721），env 816 第 248 步为 −0.012811 rad（目标 0.020599）。仅凭整组动作置零无法把故障归到一个动作维度，也不能把省略逆变换作为修复。这些事件定位的是历史 M2 动作序列中的关节失败，不能解释训练期右掌 Z 偏置的形成时间。

## 24D 映射与物理镜像

主动顺序来自 `linear_coupling.ACTIVE` 和原生 `hand.joint_names`。两手相同，顺序为 finger11、12、21、31、41、51；SDK 下标均为 [6, 11, 7, 8, 9, 10]。组切片依次为左/右手指 0–5/6–11、世界平移 12–14/15–17、腕关节内禀 XYZ 旋转 18–20/21–23。此历史模型使用 legacy 有界路径，先把 Actor 采样夹到 [−1,1]，再应用 M2 逆变换。对两次事件，Actor 索引 1 对应物理索引 7，符号保持一致。env 799 的 Actor 索引 11 为 −1.065073，夹紧并交换后成为物理索引 5 的 −1，作用于左 finger51。该饱和与右 finger12 发生在不同维度。

按厂商左右 URDF 的 joint origin RPY 将轴转到各自 base_link，在零关节角比较同名主动轴。对局部 X 反射矩阵 M=diag(−1,1,1)，转轴按轴矢量 −M 变换。finger11、21、31、41、51 的左右夹角均低于 0.001°，finger12 为 **9.448°**，其轴点积 0.98643。相同角速度符号与厂商同名关节的正向约定一致，finger12 的局部运动轴存在几何差异。该计算仅描述模型几何。

该三指 reset 的左/右 finger12 初始目标分别为 0.443364、0.031916 rad，距下界的余量不同。M2 对世界平移使用 X 反射，对内禀旋转交换左右并使用 (rx, −ry, −rz)。把三指模板左根旋转按 M·R左·M 反射，和右根旋转之间的旋转角仍为 **172.562°**。因此在这对实际 reset 上不能从分量交换和 CPU 回环恒等推出世界转轴等变。该差异应与跟踪误差分别审计，当前重放未单独替换旋转坐标系。
