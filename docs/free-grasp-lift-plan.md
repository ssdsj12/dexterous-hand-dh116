# 无阶段抓取与抬升

用户要求不分close/hold/lift，由PPO同时探索抓取及抬升；向上力奖励和向下力惩罚保留。

1. 新增显式free-grasp-lift运行模式，仅适配policy+force-region；不创建PolicyLiftHold。
2. 内部旧phase槽固定为兼容值3，无状态转换、准入、close期限或完成事件；
   观测移除4维阶段onehot。手指和掌部XYZ全程接受策略动作，保护与2–12N目标保留。
3. 法向向上及法向+摩擦支撑奖励全程评估，保留原幅度/接触区域/力上限和向下惩罚。
   移除阶段完成奖励；实际接触决定抓取参考与滑移，实际高度进展/保持决定抬升奖励。
   抬升奖励与成功不再要求原close力跟踪/轴下准入，真实双手接触仍用于确认物体被抓住。
4. 新合同/观测版本；旧分阶段checkpoint保留，新模式10240环境2048迭代从零启动。
5. CPU测试：无接触/向下力仍可动作、不受close4秒超时、复位不回close、
   双奖励全程有效、无阶段奖励、物理故障仍有效、抬升高度与真实接触检查。
6. 小规模真实Isaac复位和1轮PPO，再启动大规模；更新TensorBoard及运行状态。
