## mask、NA和真实缺口

1. flat371没有通用371D validity mask；局部grip_valid、contact_valid、effective_pad_valid并不覆盖全部字段。feedback.valid/sample_valid是sideband，不在371内；reset和invalid发布全0，invalid live guard abort保护rollout但不让0变成有效标签。训练/数据接口必须另存mask，不能按finite/0猜有效性。
2. force_region.observe:107–110把invalid contact centroid NaN置0；surface_targets给unpaired axis/imbalance补0，group=-1编码两位0；grip未捕获为0；effective sampler无载actuals/depth置0、body id=-1。这些占位不能作为有效监督。
3. 现有 `verified_support(...,legacy=True)` 是历史算术算法名，不是新的资格结论。最新state-measurement/contact-source报告明确qualified support、反力/airborne、partner ID、完整ON_OBJECT sign/frame/SI/completeness仍NA。351–354可记录现有数值但force supervision仍NA；此缺口阻断R2和正式DAgger晋级，不阻断隔离的软件实现。
4. 整手friction/rejected不能广播逐指。当前几何是固定长0.5m、半径0.008m的刚性圆柱/FK参考点，不是柔性线缆中心线/曲率、接触点或Cosserat节点。371没有完整mass/friction真值、partner ID、被动反力或硬件torque/触觉；不得为新增head暗改维度。
5. task timer、paid/window标志和内部安全投影目标含特权历史；elapsed可由合法clock候选重建不使contact_time/success_time可RGB直接恢复。未知参数不强制回归，内部terminal/success只能诊断。完整371估计仍有可观测性缺口，不能预测缺失项后静默补0。
6. 回归候选用masked Huber/SmoothL1；quaternion四维为一个SO3 geodesic组并处理物体对称性，不能逐分量MSE；bool接触可BCE/focal；interval paired是dt time-fraction回归。force未qualification一律NA/none。每样本还需run/env/episode/reset/policy tick/physics tick range/camera frame/time/calibration SHA绑定，缺图/遮挡/无深度不能补仿真真值。
